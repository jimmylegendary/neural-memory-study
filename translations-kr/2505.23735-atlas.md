## 초록 (Abstract)

Transformer는 in-context 검색(retrieval)에서의 뛰어난 성능과 대규모 학습 능력 덕분에 시퀀스 모델링의 대표적인 백본으로 자리 잡았다. 그러나 attention의 이차(quadratic) 메모리·시간 복잡도는 긴 시퀀스에 대한 적용을 제약했고, 이는 modern recurrent neural network(즉, long-term recurrent memory module)와 같은 효율적인 대안 구조를 탐구하도록 만들었다. 이러한 최근 recurrent 모델들은 다양한 downstream 과제에서 성공을 거두었지만, 여전히 **long context 이해**와 **더 긴 시퀀스로의 외삽(extrapolation)** 에서는 어려움을 겪는다.

우리는 이 한계가 세 가지 서로 독립적인 설계 결함에서 비롯된다고 본다: (1) 메모리 구조와 입력의 feature mapping에 의해 제약되는 **한정된 메모리 용량(capacity)**, (2) 메모리를 오직 마지막 입력에 대해서만 최적화하는 업데이트의 **online한 성질**, (3) 고정 크기 메모리를 다루는 **덜 표현력 있는 메모리 관리(management)**. 이 세 측면을 모두 개선하기 위해 우리는 **Atlas**를 제시한다. Atlas는 높은 용량을 갖는 long-term memory module로, 현재와 과거 토큰을 함께 고려하여 메모리를 최적화함으로써 **문맥(context)을 기억하는 법을 학습**하며, long-term memory 모델의 online한 성질을 극복한다.

이 통찰을 바탕으로 우리는 원래 Transformer 구조를 **엄밀하게 일반화(strict generalization)** 하는 새로운 Transformer류 구조군 **DeepTransformers**를 제시한다. 언어 모델링, 상식 추론(common-sense reasoning), recall-intensive 과제, long-context 이해 과제에 대한 실험 결과, Atlas는 Transformer와 최근의 선형 recurrent 모델들의 성능을 능가한다. 또한 Atlas는 Titans의 long context 성능을 더욱 개선하여, BABILong 벤치마크의 **10M 문맥 길이에서 +80% 정확도**를 달성한다.

## 1 서론 (Introduction)

Attention 모듈(Bahdanau et al. 2014)은 현대 딥러닝 구조의 핵심 구성 요소로, 확장성과 in-context 검색 성능에서 두각을 나타낸다. 원리적으로 attention은 associative memory(연상 기억)로 기능한다. 즉 토큰 쌍 사이의 직접적인 의존성을 계산하여 key-value 매핑을 저장하고, query-key 유사도를 통해 이를 검색한다. 그러나 이 쌍별 의존성 계산은 정확하지만 **이차의 공간·시간 복잡도**를 유발하여, long context 이해·기억·모델링에서의 적용을 제약한다.

이 한계를 극복하기 위한 최근 연구들은 더 효율적이면서도 효과적인 recurrent neural network를 설계해 왔다. 이러한 modern recurrent 구조들은 **'attentional bias'** 라 불리는 내부 목적함수(internal objective)를 최적화하는 associative memory 모듈로 통일적으로 이해할 수 있다(Behrouz, Razaviyayn, et al. 2025). Transformer의 커져 가는 KV cache와 달리, 이 모델들은 고정 크기 메모리를 사용하므로 더 나은 메모리 관리가 필수적이다. 이에 따라 RNN 메모리 관리를 개선하려는 세 방향의 노력이 있었다: (i) **학습 규칙(learning rule)** — additive learning에서 DeltaNet의 Delta rule까지; (ii) **Forget(Retention) gate** — RetNet의 입력 비의존적 게이팅에서 Titans·RWKV-7의 적응적 게이팅까지; (iii) **메모리 구조** — 벡터형 메모리에서 신경망 기반 deep memory 모듈까지.

이런 개선에도 불구하고 이 모델들은 여전히 long context 이해, in-context 검색, 더 긴 시퀀스로의 외삽에서 고전한다. 우리는 이 결함이 세 가지 설계적 측면에서 비롯된다고 본다:

1. **메모리 업데이트의 online한 성질** — 과거 메모리 상태는 유지한 채 현재 토큰에 대해서만 메모리를 최적화하여, 더 넓은 문맥을 고려하지 못하고 개별 토큰만을 기억한다.
2. **메모리의 한정된 용량** — 구조와 key-value feature mapping이 완벽하게 매핑 가능한 key-value 쌍의 수를 제약한다.
3. **메모리 관리(내부 목적함수의 optimizer)의 표현력 부족** — 대부분의 최근 모델이 gradient descent를 사용하는데, 이는 토큰 동역학의 1차(first-order) 정보에만 의존하여 메모리가 그릇된 국소 최소점(spurious local minima)에 수렴하고 덜 효과적인 key-value 매핑을 학습하게 만든다.

### 메모리 관점 (Memory Perspective)

Associative memory — 서로 다른 개체나 사건을 매핑하는 능력 — 는 인간 학습에서 분리할 수 없는 요소이며, 최신 딥러닝 구조를 이 관점으로 이해하려는 연구들을 촉발했다. 이 관점에서 메모리는 입력에 의해 유발되는 신경망의 갱신으로 정의된다. 즉 입력이 더 **놀라울수록(surprising)** 메모리에 더 큰 영향을 주며 더 잘 기억된다. 따라서 효과적인 **"surprise 지표"** 를 찾는 것이 이러한 메모리 모듈 설계의 핵심이다.

기존 구조들은 거의 모두 현재 입력에 기반해 메모리를 갱신하는 surprise 지표를 사용한다. 그러나 하나의 사건(토큰들의 시퀀스)은 오랜 시간 동안 일관되게 놀랍지 않더라도 기억할 만할 수 있다. 이 문제를 해결하기 위해 Titans(Behrouz, Zhong, et al. 2024)는 surprise 지표를 **"순간적(momentary)"** 놀라움과 **"과거(past)"** 놀라움의 두 부분으로 나누어, 현재 입력으로 메모리를 갱신할 때 과거 입력의 누적 놀라움을 함께 반영하도록 제안했다. 그러나 이 설계 역시 개별 토큰을 기억하다 보면 문맥을 놓칠 수 있다. 그래서 본 연구에서는 **국소적(또는 전역적) 문맥 창(window)의 놀라움을 측정**하는 long-term neural memory 모듈을 제시한다. 즉 test time에 (토큰) 문맥을 기억하는 법을 학습한다.

이 논문 전반에서 우리는 **"Test Time Memorization(테스트 시점 기억)"** 이라는 용어를 사용한다. 이 과정은 정보를 오직 전역 문맥 안에서만 저장·검색할 뿐, 모델의 사전학습된 핵심 파라미터(즉 outer-loop)나 초기 상태를 갱신하지 않기 때문이다. 메모리가 한 번 비워지면 어떤 지속적 학습이나 기술 습득도 새로운 독립적 문맥으로 넘어가지 않는다. 따라서 우리는 "test time training"보다 "test time memorization"이라는 표현을 선호한다.

### 기여 (Contributions)

앞서 언급한 세 한계 — (1) online한 성질, (2) 한정된 메모리 용량, (3) 표현력 부족한 메모리 관리 — 를 극복하기 위해, 우리는 높은 용량을 가지며 토큰이 아닌 **문맥을 기억**할 수 있는 long-term neural memory 모듈을 설계한다. 구체적으로:

- **메모리 용량과 그 병목에 대한 더 나은 이해.** 한정된 메모리 용량을 개선하기 위해 입력 토큰에 대한 고차(higher-order) feature mapping(예: 다항식 커널)을 제안한다. 왜 더 깊은 메모리 모듈과/또는 고차 feature mapping이 메모리 용량 — 메모리가 완벽하게 매핑할 수 있는 선형 독립 key-value 연상의 최대 개수 — 을 높이는지 이론적으로 정당화한다.
- **새로운 표현력 있는 학습 규칙.** 최근 recurrent 모델들의 online한 성질을 극복하기 위해, 마지막 토큰뿐 아니라 주어진 문맥 창 안의 모든 과거 토큰에 기반해 메모리를 갱신하는 sliding window 업데이트 규칙, 즉 **Omega rule**을 제시한다.
- **Transformer의 엄밀한 일반화.** Omega rule이 전역 및 국소(즉 Sliding Window Attention, SWA) softmax attention과 연결됨을 보이고, Transformer를 엄밀하게 일반화하는 새 Transformer류 구조군 **DeepTransformers**와 그 sliding window 변형 **SWDT**를 제시한다. 또한 deep memory의 역할을 보이기 위한 새로운 baseline **Deep Linear Attention (DLA)** 를 제시한다.
- **더 나은 메모리 관리를 갖춘 새 메모리 모듈.** key와 query에 다항식 feature를 쓰면서 Omega rule과 gradient descent로 메모리를 갱신하는 **OmegaNet**을 제시한다. 나아가 메모리 관리를 더 강화하기 위해, 내부 메모리 갱신에 **Muon optimizer**(Jordan et al. 2024)를 사용하는 **Atlas**를 도입한다. OmegaNet과 Atlas 모두 병렬화 가능한 학습 알고리즘을 활용하여, online 버전(즉 문맥 창 = 1) 대비 큰 오버헤드 없이 빠르게 학습된다. 우리가 아는 한 Atlas는 (근사적) **2차(second-order) 정보**로 메모리를 최적화하는 최초의 병렬화 가능한 recurrent 구조다(즉 locally optimal 메모리 모듈을 갖는다).
- **다양한 downstream 과제에서의 개선.** 언어 모델링, 상식 추론, recall-intensive, needle-in-haystack 과제에서 DeepTransformers·OmegaNet·Atlas는 modern 선형 RNN, 국소 attention(SWA), Transformer를 능가한다.

증명, 추가 실험, 관련 연구, 실험 세부는 부록에 있다.

## 2 예비 지식 (Preliminaries)

**표기(Notations).** $x \in \mathbb{R}^{N \times d_{in}}$을 입력, $M_t$를 시각 $t$에서 메모리 $M$의 상태, $K, V, Q$를 각각 key·value·query 행렬로 둔다. 시각 $t$에 해당하는 벡터는 $k_t, v_t, q_t$로 쓴다. Behrouz, Razaviyayn, et al. (2025)를 따라 $\ell(M_t; k_t, v_t)$를 **attentional bias**(내부 메모리 목적함수)로 표기한다. 메모리 모듈 $M(\cdot)$의 구조로는 $L_M \ge 1$개 층과 residual connection을 갖는 단순 MLP를 쓰지만, 모든 정식화는 다른 메모리 구조(예: $L_M = 1$인 선형 행렬형 메모리)에도 손쉽게 적용된다. 필요할 때 메모리 모듈을 $\boldsymbol{\theta}_M := \{W_1, \dots, W_{L_M}, \dots\}$로 매개변수화한다.

### 2.1 배경 (Backgrounds)

**Attention.** Attention은 Transformer의 associative memory로 작동하는 핵심 구성 요소다. 입력 $x \in \mathbb{R}^{N \times d_{in}}$에 대해, 입력 의존적 $Q = xW_Q$, $K = xW_K$, $V = xW_V$로부터 causal attention은 출력 $y \in \mathbb{R}^{N \times d_{in}}$를 다음과 같이 계산한다:

$$ y_i = \frac{1}{Z_i} \sum_{j=1}^{i} \exp\!\left(q_i^\top k_j / \sqrt{d_{in}}\right) v_j, \qquad Z_i = \sum_{\ell=1}^{i} \exp\!\left(q_i^\top k_\ell / \sqrt{d_{in}}\right). \tag{1} $$

이 식은 각 출력이 과거 value들의 query-key 유사도 가중 평균임을 뜻한다. 단순·병렬화 가능한 학습과 recall-intensive 과제에서의 효과에도 불구하고, attention은 토큰당 출력을 계산하는 데 최소 $N \times d$ 연산이 필요하여 생성 과정과 long-context 확장에서 큰 약점을 갖는다. 대안 구조들을 두 부류로 나눠 살펴본다: (1) 선형·얕은(shallow) 메모리 recurrent 모델, (2) deep memory 모듈.

**(선형) Recurrent 모델.** 선형 RNN은 병렬화 가능한 선형 시간 학습과 준수한 성능으로 효율적인 Transformer 대안으로 주목받았다. Hebbian 또는 Delta 학습 규칙에 기반한 초기 modern RNN들은 데이터를 벡터형 또는 행렬형 메모리로 압축한다. $M_t \in \mathbb{R}^{d \times n}$을 메모리($n=1$이면 벡터형), $k, v \in \mathbb{R}^d$를 key·value로 둘 때 일반적 정식화는 다음과 같다:

$$ M_t = A_t * M_{t-1} + v_t k_t^\top, \tag{2} $$

여기서 $*$는 임의의 associative 연산자, $A_t$는 데이터 (비)의존적 대각 또는 저랭크+항등 행렬이다. 이 식은 새 key-value 외적을 이전 상태(감쇠된)에 더해 넣는 선형 갱신을 뜻한다. 효율적이지만 이 메모리는 문맥이 길어질수록 넘칠 수 있고, forget gate가 관리에 도움을 주더라도 표현력은 선형 구조에 갇혀 있다.

**Deep memory 모듈.** 메모리의 표현력 한계를 극복하고 유효 문맥 길이를 늘리기 위해, 최근 연구들은 deep memory 모듈을 갖는 구조에 주목한다. 이들은 메모리가 gradient descent(모멘텀 포함)로 갱신되는 deep MLP인 메타러닝 관점에 기반한다. Behrouz, Razaviyayn, et al. (2025)는 인기 있는 시퀀스 모델들을 test time memorization의 사례로 통일하는 프레임워크를 제시했다. 즉 시퀀스 모델은 attentional bias라는 내부 메모리 목적함수를 최적화하여 주어진 key와 value 사이의 근본 매핑을 학습하는 associative memory 모듈이다. Associative memory는 형식적으로 다음과 같이 정의된다:

> **정의 1 (Behrouz, Razaviyayn, et al. 2025).** key 집합 $\mathcal{K} \subseteq \mathbb{R}^{d_k}$와 value 집합 $\mathcal{V} \subseteq \mathbb{R}^{d_v}$가 주어질 때, associative memory는 매핑 $M : \mathcal{K} \to \mathcal{V}$이다. 이 매핑의 학습은 메모리의 유형과 우선순위를 결정하는 목적함수 $\mathcal{L}$(Attentional Bias)에 기반한다:
> $$ M^* = \arg\min_M \mathcal{L}(M(\mathcal{K}); \mathcal{V}). \tag{3} $$

이 목적함수를 반복적 알고리즘(예: gradient descent)으로 최적화하면 메모리 갱신 규칙이 나온다. 따라서 시퀀스 모델은 두 최적화 수준을 갖는 메타 in-context learner다:

1. **Inner Loop:** 메모리 모듈의 파라미터 $\boldsymbol{\theta}_M = \{W_1, W_2, \dots, W_{L_M}, \dots\}$가 최적화되는 곳. 이때 다른 모든 파라미터는 하이퍼파라미터로 취급되어 고정된다.
2. **Outer Loop:** 선형 projection, MLP 층, convolution 등 모델의 나머지 파라미터가 최적화되는 곳.

우리의 용어는 이 프레임워크에 기반하므로, 완전한 recurrent 정식화 대신 모델을 (1) 메모리 구조, (2) 내부 목적함수(attentional bias), (3) 메모리 학습 알고리즘(optimizer)으로 서술한다.

## 3 테스트 시점에 문맥을 기억하는 법 배우기 (Learning to Memorize the Context at Test Time)

Long-term associative memory는 인간 학습에 필수적이며 여러 인공 신경망 구조에 영감을 주었다. 많은 모델이 과거 데이터를 압축하기 위해 행렬형·벡터형 메모리를 쓰지만, 최근 연구들은 과거의 추상을 파라미터에 부호화하는 deep 비선형 신경 메모리를 옹호한다. 그러나 long-context 추론/이해를 위해서는 이 long-term neural memory 모듈이 여전히 다음을 필요로 한다: (1) **높은 용량** — 파라미터에 저장 가능한 최대 (key, value) 쌍 수(§3.1); (2) key-value의 복잡한 매핑을 학습할 **강력한 내부 목적함수(attentional bias)**(§3.2); (3) 고정 크기 메모리를 위한 **강력한 메모리 관리**(§3.2); (4) 대규모 학습을 위한 **효율적 병렬 학습 과정**(§3.3).

### 3.1 초선형 용량을 갖는 Associative Memory (Associative Memory with Super Linear Capacity)

고정된 수의 메모리 파라미터로 저장할 수 있는 **상관 없는(uncorrelated) (key, value) 쌍의 최대 개수는 얼마인가?** 이 질문에 답하기 위해 가장 단순한 경우 — 행렬 메모리, attentional bias로 $\ell_2$ 회귀 손실 $\ell(M_t; k_t, v_t) = \|M_t(k_t) - v_t\|_2^2$, gradient descent 최적화 — 부터 시작한다:

> **명제 1 ($\ell_2$ Attentional Bias의 용량).** $d_v \times d_k$개 파라미터를 갖는 행렬형 메모리 $M$이 $\ell(M_t; k_t, v_t) = \|M_t k_t - v_t\|_2^2$를 gradient descent로 최적화한다고 하자. $M$은 선형 독립인 key를 갖는 $(k_i, v_i)$ 쌍을 최대 $O(d_k)$개 저장할 수 있다.

이 명제는 delta 갱신 규칙을 쓰는 행렬형 메모리가 파라미터 수에 비해 **부(sub)선형** 용량을 가짐을 뜻한다. 즉 크기 $M$인 고정 메모리가 저장할 수 있는 독립 패턴의 수는 어떤 $c \in \mathbb{R}^+$에 대해 $c \times M$보다 엄격히 작다. 최근 모델들은 deep memory 모듈을 제안하지만, 이것이 용량을 실제로 높이는지는 불분명했다.

> **정리 1 (Deep Memory의 효과).** $M(\cdot)$을 $L_M \ge 2$개 층, 입력 차원 $d_k$, 은닉 차원 $d_h$를 갖는 MLP라 하자. 그러면 $M(\cdot)$은 선형 독립 key를 갖는 $(k_i, v_i)$ 쌍을 최소 $O(d_k d_v)$개, 최대 $O\!\left(d_k d_v \sum_{i=1}^{L_M} \min_{j \ge i}\{d_h^{(j)}\}\, d_h^{(i+1)}\right)$개 저장할 수 있다.

이 정리는 deep memory가 표현력뿐 아니라 용량도 높이며 그 이점이 깊이에 따라 커짐을 뜻한다. 그러나 상한은 여전히 key·value 차원에 대해 **부이차(subquadratic)** 이므로, long-term memory가 초선형 용량을 달성할 수 있는지가 여전히 문제로 남는다.

용량을 늘리려면 $k_t$의 차원이 관건이지만, 모든 key·value 차원을 단순히 키우면 파라미터 수($d_{in}$당 $O(d_{in})$)와 메모리 사용량이 크게 늘어난다. 이를 해결하기 위해, key와 query에 대해 **분리 가능한 커널(separable kernel)** $\sigma(x, y) = \phi(x)^\top \phi(y)$를 쓸 것을 제안한다. 그 예로 차수 $p$ 이하의 다항식 커널에 집중한다. $p \in \mathbb{N}$에 대해 $\phi_p(x) = [x^\beta]_{|\beta| \le p}$를 $x$의 차수 $p$ 이하 다항식 mapping이라 하자. 정의 1의 목적함수 $\mathcal{L}(M(\mathcal{K}); \mathcal{V})$를 $\mathcal{L}(M(\phi(\mathcal{K})); \mathcal{V})$로 대체한다. 이 다항식 mapping은 **입력 projection에 추가 파라미터 없이** key의 유효 차원을 키운다.

> **명제 2 (다항식 Mapping을 이용한 메모리 용량).** $\phi_p(\cdot)$을 차수 $p$ 이하 다항식 mapping, $M$을 $\ell(M_t; \phi_p(k_t), v_t) = \|M_t \phi_p(k_t) - v_t\|_2^2$를 gradient descent로 최적화하는 행렬형 메모리라 하자. $M$은 선형 독립 key를 갖는 $(k_i, v_i)$ 쌍을 최대 $O(d_k^p)$개 저장할 수 있다.

이 명제는 key에 대한 다항식 커널이 입력 projection 파라미터를 늘리지 않고도 **다항식만큼 더 많은 용량**을 사줌을 뜻한다. 다항식 mapping은 두 관점으로도 정당화된다. 선형 메모리와 두 attentional bias $\ell^{(1)}(M_t; k_t, v_t) = \langle M_t k_t, v_t\rangle$, $\ell^{(2)}(M_t; k_t, v_t) = \|M_t \phi(k_t) - v_t\|_2^2$를 예로 든다. 이를 gradient descent로 풀면 다음 recurrence가 나온다:

$$ \ell^{(1)}: \quad M_t = M_{t-1} + \eta_t v_t \phi(k_t)^\top, \qquad \text{(Hebbian Rule)} $$

$$ \ell^{(2)}: \quad M_t = \left(I - \eta_t \phi(k_t)\phi(k_t)^\top\right) M_{t-1} + \eta_t v_t \phi(k_t)^\top. \qquad \text{(Delta Rule)} $$

앞의 식은 새 연상을 단순히 더하는 Hebbian 규칙, 뒤의 식은 기존 예측을 빼고 갱신하는 Delta 규칙을 뜻한다.

**(1) Softmax 근사 관점.** Hebbian 규칙은 커널 선형 attention과 동치이며, 여기서 $\phi(\cdot)$의 역할은 softmax(정확히는 지수 커널)를 근사하는 것이다. 정규화가 있는 지수 커널(즉 softmax)은 분리 불가능하여 Transformer의 이차 복잡도를 유발한다. 그러나 지수 feature map 커널은 Taylor 급수로 근사할 수 있다:

$$ \exp\!\left(q_i^\top k_j\right) \approx 1 + q_i^\top k_j + \frac{(q_i^\top k_j)^2}{2!} + \frac{(q_i^\top k_j)^3}{3!} + \cdots \tag{4} $$

우리의 다항식 feature map은 이를 더 일반화한다:

$$ \exp\!\left(q_i^\top k_j\right) \approx \phi_p(q)\phi(k)^\top = a_0 + a_1 q_i k_j^\top + a_2 (q_i^\top k_j)^2 + a_3 (q_i^\top k_j)^3 + \cdots + a_p (q_i^\top k_j)^p, \tag{5} $$

여기서 학습 가능한 계수 $a_i \in \mathbb{R}$는 $a_i = \frac{1}{i!}$로 초기화된다. 이 식은 다항식 커널이 학습 가능한 계수를 갖는 **절단된(truncated) softmax 커널 근사기**임을 뜻한다. 이 직관은 deep memory와 더 복잡한 attentional bias로도 일반화된다.

**(2) 입력 게이팅(Input Gating) 관점.** 계수 $a_i$는 입력 feature 게이팅으로 볼 수 있다. $a_i \to 0$은 차수 $i$의 feature map $[x_j]_{|j|=i}$를 배제, $a_i \to 1$은 해당 feature를 유지함을 뜻한다. 이는 RNN의 게이팅과 비슷하되 메모리가 아닌 **입력에 적용**된다. 모델이 $i \ne 1$인 모든 $a_i \to 0$, $a_1 \to 1$을 학습하면 단순한 $\phi(x) = x$가 복원되므로 표현력이 더 크다.

### 3.2 문맥 기억을 갖는 Long-term Memory (Long-term Memory with Context Memorization)

대부분의 기존 recurrent 모델의 결정적 약점은 이전 메모리 상태는 유지한 채 현재 입력에 대해서만 내부 목적함수를 최적화하는 online한 성질이다:

$$ \min_M \ell(M; k_t, v_t) + \text{Ret}_t(M, M_{t-1}), \tag{6} $$

여기서 $\text{Ret}(\cdot, \cdot)$은 retention gate다. 이 식은 새 토큰의 손실과 이전 상태 유지항을 함께 최소화함을 뜻한다. 이 online한 성질은 최적화를 단순·빠르게 하지만, 메모리가 개별 토큰을 탐욕적으로 기억하여 문맥을 준최적으로만 기억하게 만든다. 더 일반적으로는 각 시점에 전체 문맥에 대해 메모리를 최적화할 수 있다:

$$ \min_M \sum_{i=1}^{t} \ell(M; k_i, v_i). \tag{7} $$

이 식은 지금까지의 모든 토큰을 동시에 잘 저장하도록 메모리를 맞춤을 뜻한다. 그러나 이 엄격한 전역 정식화는 두 한계가 있다: (1) **효율성** — 모든 과거 토큰에 대해 최적화하면 매 갱신마다 추가 제약이 생겨 극단적으로 긴 시퀀스에서 비효율적이고, test time에 과거 key·value를 캐싱해야 하여 메모리 소비가 늘어난다. (2) **문맥 가지치기(pruning)** — 큰 문맥 과제에서 모든 과거 토큰으로 최적화하면 시퀀스 중간의 문맥 변화나 무관한 문맥 때문에 준최적이 될 수 있다.

이를 해결하기 위해, 과거 토큰의 **창(window)** 에 대해 attentional bias를 최적화하는 sliding window recurrent 모델을 제시한다. 메모리 모듈 $M(\cdot)$과 창 길이 $c \ge 1$에 대해:

$$ \min_M \sum_{i=t-c+1}^{t} \gamma_i^{(t)}\, \ell(M; k_i, v_i), \tag{8} $$

여기서 $\gamma_i^{(t)}$는 최적화에서 $i$번째 토큰의 영향에 대한 감쇠항이다. 이를 바탕으로, 인기 있는 Delta 학습 규칙보다 엄밀하게 더 강력한 **Omega rule**을 제시한다:

> **Omega Rule.** key $k_i \in \mathbb{R}^{d_k}$, value $v_i \in \mathbb{R}^{d_v}$, 메모리 모듈 $M(\cdot)$, 국소 문맥 길이 $c \in \mathbb{N}_{\ge 1}$가 주어질 때, Omega 학습 규칙에 의한 메모리 갱신은 다음 손실을 gradient descent로 최적화하는 것으로 정의된다:
> $$ \min_M \sum_{i=t-c+1}^{t} \gamma_i^{(t)}\, \|M(k_i) - v_i\|_2^2. \tag{9} $$

이 갱신 규칙은 $\ell_2(\cdot)$을 $\ell_q(\cdot)$로 바꿔 $q$-Omega rule로도 확장된다. 극단적 경우로 (1) $c = 1$이면 갱신이 online(Delta rule)이 되고, (2) $c = \infty$(또는 문맥 길이)이면 모든 과거 토큰에 대한 전역 최적화가 된다. 파라미터 $\gamma_i^{(t)} \in [0, 1]$은 과거 토큰에 대한 **하드(직접) 게이트**로 작동한다. $\gamma_i^{(t)} \to 0$이면 $i$번째 토큰의 최적화를 직접 가지치기하고, $\gamma_i^{(t)} \to 1$이면 완전히 포함시킨다. 우리는 $\gamma_i^{(t)}$에 입력 의존적 파라미터를 써서 **in-context 가지치기** 능력을 제공한다. sliding window recurrence 설계 덕분에 토큰당 상수 개수($\{\gamma_i^{(t)}\}_{i=1}^c$)의 게이트만 필요해 이런 유연성이 가능하다. 전역 최적화(식 7)에 입력 의존적 게이트를 쓰면 파라미터·메모리가 크게 늘어 recurrent 모델의 이점이 사라진다.

**OmegaNet.** 이제 Omega rule로 메모리를 갱신하는 새 시퀀스 모델 OmegaNet을 제시한다. 용량을 높이기 위해 key와 query에 다항식 커널을 쓴다. 식 9를 최적화하면 OmegaNet의 갱신 규칙은:

$$ M_t = \alpha_t M_{t-1} - \nabla \underbrace{\sum_{i=t-c+1}^{t} \gamma_i^{(t)} \|M(\phi(k_i)) - v_i\|_2^2}_{\text{문맥의 surprise}}, \tag{10} $$

또는 선형 메모리 특수한 경우에:

$$ M_t = \left(\text{diag}(\alpha_t) - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} \phi(k_i)\phi(k_i)^\top\right) M_{t-1} - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} v_i \phi(k_i)^\top. \tag{11} $$

이 식은 (gated) delta rule의 rank-1 전이 $(I - \beta_t k_t k_t^\top)$를 **rank-$c$로 일반화**한 것을 뜻한다. 메모리 관점에서 Omega rule(OmegaNet)은 토큰의 surprise가 아니라, 문맥 내 개별 토큰들의 문맥 인지적 조합에 기반한 **국소 문맥의 surprise**를 측정한다.

**Gradient Descent를 넘어서.** Omega rule과 "문맥의 test time memorization"은 식 9를 임의의 optimizer로 최적화하도록 확장된다. 두 극단을 예로 든다. 첫째, $c = 1$, $\gamma_i^{(t)} = 1$, gradient descent with momentum을 쓰면:

$$ M_t = \alpha_t M_{t-1} + S_t, \tag{12} $$
$$ S_t = \theta_t S_{t-1} - \eta_t \nabla\ell(M_{t-1}; k_t, v_t). \tag{13} $$

이 갱신 규칙은 **Titans의 long-term neural memory와 동치**다. 둘째, 선형 메모리 $M$, $\gamma_i^{(t)} = 1$, $c$를 문맥 길이로 두면 (정규화된) 최소제곱 문제를 최적화하는 것과 동치가 된다:

$$ M_t = \min_M \sum_{i=1}^{t} \|Mk_i - v_i\|_2^2. \tag{14} $$

Von Oswald et al. (2023)는 이를 직접 최적화하고 최적해의 역행렬 항을 Sherman-Morrison 공식으로 재귀적으로 계산할 것을 제안했다(Mesa-layer). 그러나 이 직접 해는 병렬화 불가능한 학습 비용을 수반하고 선형 행렬형 메모리에만 제한되며, 하드 게이팅항($\gamma_i^{(t)}$)이 없어 문맥을 가지치기하지 못해 긴 시퀀스에서 성능을 해친다.

### 3.3 Omega Rule의 병렬화 (Parallelizing Omega Rule)

Omega rule이 Hebbian·Delta 규칙보다 일반적이고 표현력 있지만, 대규모 모델 적용은 학습 효율에 달려 있다. online 버전($c = 1$) 대비 큰 오버헤드 없는 빠른 병렬 학습 알고리즘을 논한다. 소박한 구현은 위치마다 $c$개의 gradient $\nabla\ell \in \mathbb{R}^{d_{in} \times d_{in}}$을 실체화해야 하여 $d_{in}$이 클 때 메모리·I/O 비용이 크다. 또 TPU·GPU를 충분히 활용하려면 연산을 텐서화하고 matmul을 극대화해야 한다. 이에 큰 메모리 오버헤드 없이 병렬 학습을 지원하는 **sliding window masking 전략**을 제안한다.

길이 $L$ 시퀀스를 크기 $b \ge 1$의 청크 $S_i = \{x_{(i-1)b+1}, \dots, x_{ib}\}$로 나눈다. 각 청크에서 gradient는 **이전 청크의 마지막 상태에 대해** 계산한다. 명료함을 위해 $\gamma_i^{(t)} = \eta_t$로 두면, 청크 크기 $b = 1$일 때 갱신 규칙은:

$$ M_t = \alpha_t M_{t-1} - \eta_t \sum_{i=t-c+1}^{t} \nabla\ell(M_{t-1}; k_i, v_i). \tag{15} $$

실제로는 완전 recurrent와 완전 병렬 사이 균형을 위해 시퀀스를 청크로 나눠, 청크 내부(intra-chunk)는 병렬, 청크 간(inter-chunk)은 recurrent로 계산한다. $t' = t - \text{mod}(t, b)$로 두면, $t' \le t < t' + b$인 시점에 대해 청크 내 갱신 규칙은:

$$ M_t = \alpha_t \dots \alpha_{t'} M_{t'} - \underbrace{\sum_{n=t'}^{t} \alpha_n \dots \alpha_{t'}\, \eta_n \sum_{i=n-c+1}^{n} \nabla\ell(M_{t'}; k_i, v_i)}_{G_t}. \tag{16} $$

$G_t$는 Titans와 같은 방식의 gradient 계산에, broadcasting(예: einsum) 시 **sliding window mask $M_s$** 를 추가로 적용해 얻는다. $c = 1$이면 $M_s$는 항등 행렬로 줄어든다. $c > 1$이면 $M_s$는 각 대각 원소 바로 앞 $c-1$개 위치도 1로 설정한 항등 행렬이다. 이로써 청크 내 모든 gradient를 실체화하지 않고도 크기 $c$의 창에서 gradient 기여를 합할 수 있다.

## 4 DeepTransformers: Deep Memory를 갖는 Transformer (DeepTransformers: Transformers with Deep Memory)

최근 연구들은 Transformer를 associative memory 관점에서 폭넓게 논해 왔다. 그렇다면 우리의 메모리 용량 및 Omega rule 논의가 Transformer에 어떤 영향을 주는지 묻는 것은 자연스럽다. 이 절에서는 Omega rule이 Transformer 및 그 sliding window 대응물(SWA)과 어떻게 연결되는지 논하고, Transformer를 각각 엄밀하게 일반화하는 두 확장을 제시한다.

### 4.1 메모리의 Online 및 국소 문맥 최적화 (Online and Local Context Optimization of Memory)

**Sliding Window Attention과의 연결.** Softmax attention 블록은 Nadaraya-Watson 추정량을 이용한 $\ell_2(\cdot)$ 회귀의 **비모수(non-parametric) 해**로 재정식화된다:

$$ M^* = \arg\min_M \sum_{i=1}^{L} s(k_i, q) \|v_i - M\|_2^2 = \sum_{i=1}^{L} \frac{s(k_i, q)}{\sum_{j=1}^{L} s(k_j, q)} v_i, \tag{17} $$

여기서 $L$은 시퀀스 길이다. 이 식은 attention이 각 query에 대해 key 유사도로 가중된 value 평균으로 메모리를 전역 최적화함을 뜻한다. 최적화를 과거 $c$개 토큰으로 제한하면:

$$ M^* = \arg\min_M \sum_{i=t-c+1}^{t} s(k_i, q_i) \|v_i - M\|_2^2 = \sum_{i=t-c+1}^{t} \frac{s(k_i, q)}{\sum_{j=t-c+1}^{t} s(k_j, q)} v_i, \tag{18} $$

이는 **sliding window attention (SWA)** 와 동치다. 이 연결은 중요한 통찰을 준다: attention은 비모수 해일 뿐 아니라 내부 목적함수(attentional bias)를 **전역적으로** 최적화하는 반면, 최근 modern recurrent 모델들은 대부분 online learner다. 우리의 sliding window RNN과 Omega rule은 과거 토큰 창에 대해 모수적으로 메모리를 최적화하여 이 간극을 메우며, 개별 토큰이 아닌 문맥을 효과적으로 기억한다.

> 참고(각주): 두 예외는 Titans와 Mesa-layer다. Mesa-layer는 모든 과거 토큰에 대해 최적화하지만 느린 학습 비용을 치르고, Titans는 모든 과거 토큰에 대해 최적화하되 각 과거 토큰에 대한 암묵적 감쇠항(모멘텀의 결과)을 두어 병렬화를 유지한다.

**Deep Linear Attention (DLA).** 새 baseline으로, (gated) 선형 attention의 행렬형 메모리를 deep 신경망($k$층 MLP)으로 대체한 Deep (Gated) Linear Attention을 제시한다. 내적 유사도를 attentional bias로 쓰고 gradient descent로 최적화한다:

$$ M_t = \alpha_t M_{t-1} - \eta_t \nabla\ell(M_{t-1}; \phi(k_t), v_t), \tag{19} $$

여기서 $\ell(M_{t-1}; \phi(k_t), v_t) = \langle M_{t-1}(\phi(k_t)), v_t\rangle$이고 $\phi(\cdot)$은 다항식 커널이다. DLA는 선형/비선형 청크 학습의 혼합으로 손쉽게 병렬화된다.

**Sliding Window Linear Attention (SWLA).** SWA와의 연결을 바탕으로, 내적 유사도를 attentional bias로 쓰고 sliding window 손실을 gradient descent로 최적화하는 SWLA 블록을 제시한다. 선형 메모리로 닫힌 형태를 유도하면:

$$ M_t = \alpha_t M_{t-1} - \eta_t \nabla \sum_{i=t-c+1}^{t} \ell(M_{t-1}; \phi(k_i), v_i) = M_{t-1} + \sum_{i=t-c+1}^{t} \gamma_i^{(t)} v_i \phi(k_i)^\top. \tag{20} $$

online($c = 1$)이고 $\phi(\cdot) = (\cdot)$이면 이는 선형 attention과 같다.

### 4.2 메모리 용량과 지수 커널 (Memory Capacity and Exponential Kernels)

먼저 Transformer의 softmax attention(식 1)을 다시 쓴다:

$$ y_i = \frac{1}{\sum_{\ell=1}^{i} \exp(q_i^\top k_\ell / \sqrt{d_{in}})} \sum_{j=1}^{i} \exp\!\left(q_i^\top k_j / \sqrt{d_{in}}\right) v_j. \tag{21} $$

이 $\exp(\cdot)$ 커널은 분리 불가능하여 recurrence로 쓸 수 없다. 그러나 $\exp(\cdot)$ 커널은 입력을 **무한 차원**으로 보내는 feature map으로 볼 수 있다. 즉 다음을 정의한다:

$$ \phi^*(x) = \left(1,\; x,\; \frac{x^{\otimes 2}}{\sqrt{2!}},\; \frac{x^{\otimes 3}}{\sqrt{3!}},\; \dots\right)^\top, \qquad \phi_p(x) = x^{\otimes p}, \tag{22} $$

여기서 $x^{\otimes p} = x \otimes x^{\otimes(p-1)}$는 Kronecker 곱을 이용한 "self-tensoring" 연산자이고, 따라서:

$$ \exp(q_t^\top k_t) = \phi^*(q_t)^\top \phi^*(k_t). \tag{23} $$

이 식은 지수 커널이 무한 차원 공간으로의 분리 가능한 커널임을 뜻한다. 이 커널로 attention(식 21)을 재정식화하면($1/\sqrt{d_{in}}$은 단순화를 위해 생략):

$$ y_i = \frac{1}{\sum_{\ell=1}^{i} \exp(q_i^\top k_\ell)} \left(\sum_{j=1}^{i} v_j \phi^*(k_j)^\top\right) \phi^*(q_i) = M_i \phi^*(q_i). \tag{24} $$

이 정식화는 또 다른 중요한 통찰을 준다: **associative memory로서의 softmax attention은 무한(unbounded) 메모리를 가지므로 더 큰 문맥을 파라미터에 더 잘 기억할 수 있다.** 이 통찰을 바탕으로, DLA(식 19)에서 다항식 커널을 $\phi^*(\cdot)$ 커널로 대체하여 **DeepTransformers**를 제시한다(정규화 없는 형태):

$$ M_t = M_{t-1} - \nabla\langle M_{t-1}(\phi^*(k_t)), v_t\rangle. \tag{25} $$

선형 메모리 특수한 경우 닫힌 형태는:

$$ M_t = M_{t-1} + v_t \phi^*(k_t)^\top = \sum_{i=1}^{t} v_i \phi^*(k_i)^\top \;\Rightarrow\; y_t = M_t \phi^*(q_t) = \sum_{i=1}^{t} v_i \exp(q_i^\top k_i), \tag{26} $$

이는 **정규화 없는 Transformer의 출력과 정확히 일치**한다. 따라서 DeepTransformers는 softmax attention을 갖는 Transformer의 엄밀한 일반화다.

### 4.3 Deep Omega Transformer (Dot): Omega 학습 규칙을 갖는 Transformer

위 DeepTransformers는 원래 Transformer처럼 Hebbian 규칙에 기반한다. 그러나 더 강력한 메모리 관리·학습 규칙을 쓰면 성능을 더 높일 수 있다. Hebbian 규칙을 Omega 학습 규칙으로 대체하여, 정규화 없는 **Deep Omega Transformers (Dot)** 를 얻는다:

$$ M_t = M_{t-1} - \nabla \sum_{i=t-c+1}^{t} \gamma_i^{(t)} \|M(\phi^*(k_i)) - v_i\|_2^2. \tag{27} $$

**선형 메모리.** 이 경우 정규화 없는 정식화는:

$$ M_t = \left(I - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} \phi^*(k_i)\phi^*(k_i)^\top\right) M_{t-1} - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} v_i \phi^*(k_i)^\top, \tag{28} $$

$$ y_t = M_t \phi^*(q_t) = \left(I - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} \phi^*(k_i)\phi^*(k_i)^\top\right) M_{t-1}\phi^*(q_t) - \sum_{i=t-c+1}^{t} \gamma_i^{(t)} v_i \exp(q_t^\top k_i). \tag{29} $$

**$c = 1$인 online 경우.**

$$ M_t = \left(I - \eta_t \phi^*(k_t)\phi^*(k_t)^\top\right) M_{t-1} - \eta_t v_t \phi^*(k_t)^\top, \tag{30} $$

$$ y_t = M_t \phi^*(q_t) = \left(I - \eta_t \phi^*(k_t)\exp(q_t^\top k_t)\right) M_{t-1} - \eta_t v_t \exp(q_t^\top k_t). \tag{31} $$

이 (정규화 없는) 정식화는 **"Delta rule을 갖는 Transformer"** 의 일반화로 볼 수 있다. 무한 메모리 덕분에 Dot은 새 key·value를 (원래 Transformer처럼) 덧붙일 뿐 아니라, 해당 key에 대해 이전 상태에서 예측한 value로 새 value를 대체(오차 정정)한다.

## 5 Atlas: 높은 용량을 갖는 Locally Optimal 메모리 (Atlas: A Locally Optimal Memory with High Capacity)

Omega rule로 토큰이 아닌 문맥을 기억하고 다항식(또는 지수) feature mapping으로 용량을 높였더라도, 메모리 관리(즉 key-value 매핑의 최적화)는 여전히 단순한 gradient descent에 갇혀 있다. 이 optimizer는 모델을 낮은 품질의 국소 최적점으로 이끌어 긴 문맥에서 성능을 해칠 수 있다. 이를 극복하기 위해, 2차 정보를 근사하면서 대부분 행렬 곱을 사용하고 시퀀스 방향으로 병렬화 가능한 **Muon optimizer**(가중치 감쇠 포함)를 쓸 것을 제안한다. Muon으로 식 9의 내부 목적함수를 최적화하면:

$$ M_t = \alpha_t M_{t-1} - \eta_t\, \text{NewtonSchulz-}k(S_t), \tag{32} $$
$$ S_t = \theta_t S_{t-1} + \nabla \sum_{i=t-c+1}^{t} \gamma_i^{(t)} \|M(\phi^*(k_i)) - v_i\|_2^2, \tag{33} $$

여기서 $c$는 국소 문맥 길이, $k$는 Newton-Schulz 연산의 반복 횟수다. Muon 문헌에 따르면 $k \to \infty$일 때 $\text{NewtonSchulz-}k(S_t)$는 모멘텀 항 $S_t$에 가장 가까운 **준직교(semi-orthogonal) 행렬**로 수렴하여 2차 정보를 더 낮은 오차로 근사한다. 따라서 흥미롭게도 파라미터 $k$는 Atlas의 **내부 test-time compute 파라미터**로 볼 수 있으며, 더 많은 스텝을 쓰면 잠재적으로 더 나은 기억이 가능하다.

### 5.1 병렬 학습 (Parallel Training)

Atlas의 학습이 어떻게 병렬화되는지 논한다. 명료함을 위해 $c = 1$로 가정한다(임의의 $c$로의 일반화는 §3.3을 따른다). §3.3처럼 시퀀스를 청크로 나누고 gradient를 이전 청크의 마지막 상태에 대해 계산한다. 모멘텀은 있으나 Newton-Schulz는 아직 없는 Atlas의 recurrence는:

$$ M_t = \alpha_t M_{t-1} + S_t, \tag{34} $$
$$ S_t = \theta_t S_{t-1} - \eta_t \nabla\ell(M_{t'}; k_t, v_t). \tag{35} $$

$t'$가 이전 청크의 마지막 상태이므로 모든 gradient를 미리 계산할 수 있어 $u_t = \nabla\ell(M_{t'}; k_t, v_t)$로 둔다. 그러면:

$$ M_t = \alpha_t M_{t-1} + S_t, \qquad S_t = \theta_t S_{t-1} - \eta_t u_t. \tag{36, 37} $$

둘째 recurrence를 전개하면:

$$ S_t = \theta_t \dots \theta_1 S_0 - \sum_{i=1}^{t} \frac{\theta_t \dots \theta_1}{\theta_i \dots \theta_1} \eta_i u_i = \beta_t S_0 - \Theta \odot E \odot G, \tag{38, 39} $$

여기서 $\beta_t = \theta_t \dots \theta_1$, $G$는 gradient 행렬, $E$와 $\Theta$는 각각 $\eta$·$\theta$ 값의 대각 행렬, $\odot$은 broadcasting이다. 이 청크별 recurrence의 핵심 이점은 **모멘텀의 recurrence가 메모리 상태와 독립**이라는 점이다. 즉 청크 시작에서 모든 모멘텀 항을 병렬로 계산할 수 있다. Muon의 경우 이 모멘텀 항들에 Newton-Schulz를 적용한다:

$$ S_t' \leftarrow \text{Newton-Schulz5}(S_t), \qquad M_t = M_{t-1} + S_t'. \tag{40, 41} $$

모든 $S_t$를 병렬로 계산할 수 있으므로 $\text{Newton-Schulz5}(\cdot)$도 병렬로 계산할 수 있다. 이로써 Atlas는 (근사적) 2차 내부 optimizer를 갖는 최초의 병렬화 가능한 recurrent 구조가 된다.

**구조 백본(Architectural Backbone).** 최근 modern recurrent 모델들을 따라, key·value·query를 선형 층으로 projection한 뒤 크기 4의 짧은 convolution 층을 둔다. 학습 안정화를 위해 key와 query에 정규화를 적용한다. Titans를 따라 두 하이브리드 변형 MAL·MAG도 쓴다(그림 3). Deep memory 구조에서는 residual connection을 갖는 2층 MLP를 쓴다:

$$ M(\cdot) = (\cdot) + W_1 \sigma(W_2(\cdot)). \tag{42} $$

이 메모리 구조를 **gated MLP** 층으로 더 확장하면:

$$ M(\cdot) = (\cdot) + W_1\left(\sigma(W_2(\cdot)) \otimes W_3(\cdot)\right), \tag{43} $$

여기서 $W_1, W_2, W_3$은 학습 가능한 선형 행렬이다. 이 메모리 구조를 갖는 Atlas를 **Atlas++** 라 부른다.

### 6.4 학습 가능성 실험 (Learnability Experiments)

작은 MLP가 online 방식으로 함수를 학습하는 능력을 분석했다. 튜플 시퀀스 $(i_1, o_1), \dots, (i_t, o_t)$($i_j, o_j \in \mathbb{R}^d$)에 대해, MLP $M$을 online으로 학습하여 손실 $\text{loss}_j = \|i_j - o_j\|_2^2 / \|o_j\|_2^2$를 최소화한다. 시각 $j$에서 gradient $\nabla_{M.\text{params}}\, \text{loss}_j$를 계산하고 Adam, RMSprop, SGD로 파라미터를 갱신한다. 다섯 가지 시퀀스-투-시퀀스 함수를 연구한다:

1. **Low Rank Mappings:** 무작위 저랭크 행렬 $W = XY$($X \in \mathbb{R}^{d \times k}$, $Y \in \mathbb{R}^{k \times d}$)로 $o_j = W^\top i_j$.
2. **MLP Mappings:** 1입력·1은닉·1출력 MLP $M$(GELU, 확장 없음)로 $o_j = M(i_j)$.
3. **Attention+MLP Mapping:** causal masked attention을 입력에 적용해 $o'_j$를 얻고 $o_j = M(o'_j)$.
4. **Attention Outputs as Inputs:** 위와 같되 $o'_j$를 입력, $o_j$를 출력 시퀀스로.
5. **Sliding Window Attention + MLP Mapping:** 설정 3과 같되 full attention 대신 창 512의 sliding window attention 사용.

$d = 256$으로 두고 다섯 설정의 위치별 손실 곡선을 그림 6에 보인다. 모든 설정에서 모델은 결국 $\text{loss}_j < 1$인 비자명한 매핑을 학습한다. 설정 4의 attention이 유발한 입력 상관 덕분에 설정 2보다 빠르게 학습되고, 가장 단순한 설정 1에서 대체로 가장 잘 학습된다. 모델은 이전 입력·출력을 (부분적으로) 기억해야 하는 설정 3과 5에서 가장 못한다. 흥미롭게도 용량 요구가 더 클 것으로 예상되는 설정 3이 설정 5보다 오히려 더 잘 학습되는데, 우리는 학습 알고리즘이 **오래된 입력을 '잊지(forget)' 못하기** 때문에 sliding window 설정(5)에서 손실이 더 나빠진다고 가정한다. 다만 attention이 무작위 초기화 벡터에서 계산되어 attention 행렬이 (학습된 LLM처럼) 뾰족하지 않다는 점은 분석의 한계다.

## 7 결론 (Conclusion)

우리는 modern recurrent 모델의 핵심 한계 — 한정된 메모리 용량, online 전용 갱신, 약한 메모리 관리 — 를 다루기 위해 새 long-term memory 모듈 **Atlas**를 도입했다. 제안한 sliding window 학습 규칙, 고차 feature mapping, 진보한 메모리 optimizer는 이 도전을 극복하는 원리적이고 확장 가능한 접근을 제공한다. 실증적으로 우리 모델들(OmegaNet, Atlas, DeepTransformers, Dot)은 다양한 벤치마크에서 Transformer와 최근 RNN 변형 대비 일관된 개선을 이룬다. 이론적으로 우리는 메모리 용량과 최적화 동역학에 대한 통찰을 제공하여, 선행 연구에서 관찰된 문맥 길이 한계에 대한 설명을 제시했다.

## 부록 (Appendix)

### 부록 A. 추가 관련 연구 (Additional Related Work)

**Modern 선형 Recurrent Neural Network.** Transformer의 이차 복잡도와 long-context 한계를 완화하기 위한 효율적 recurrent 대안들이 개발되었다. 초기(RetNet, RWKV, S5)는 데이터 비의존적 전이 행렬과 Hebbian 유사 갱신을 썼고, 이후 세대는 입력 의존적 파라미터를 도입했다(선형 RNN, RWKV6). 이들은 delta rule 기반의 더 표현력 있는 갱신 규칙도 탐구했다. 나아가 deeper 모델로 확장하며 delta-rule 유사 갱신(TTT)이나 forget gating을 갖는 데이터 의존적 모멘텀 갱신(Titans)을 활용했다. 최근 Siems et al. (2025)은 토큰당 다중 gradient descent 갱신을 적용해 특히 state tracking에서 더 표현력 있는 모델을 제안했다. 비선형 recurrence를 갖는 RNN과 그 빠른 학습에 대한 연구도 있다.

**Fast Weight Programs.** 선형 층을 key-value associative memory로 보는 개념은 Hopfield network로 거슬러 올라가며, 이후 fast weight programmer 맥락에서 동적 fast program을 RNN에 통합해 쓰기 가능한 메모리로 삼았다. 학습 패러다임으로는 Hebbian 학습과 delta rule이 가장 두드러진다.

**Hopfield Networks.** 우리의 정식화는 key-value 매핑 학습이라는 associative memory의 넓은 개념 위에 세워져 있다. Hopfield(1982)는 에너지 함수 최소화로 key-value 쌍을 저장하는 초기 신경 구조를 도입했다. 전통적 Hopfield network는 벡터형 메모리 용량 한계로 쓰임이 줄었으나, 여러 연구가 지수 커널을 에너지 함수에 도입하는 등으로 용량을 강화했고, 현대화된 Hopfield network와 Transformer의 관계도 연구되었다.

### 부록 B. Miras 프레임워크 (Miras Framework)

Behrouz, Razaviyayn, et al. (2025)는 associative memory를 정의 2로 형식화했다(정의 1과 동일한 $M^* = \arg\min_M \mathcal{L}(M(\mathcal{K}); \mathcal{V})$, 식 44). 이 목적함수를 반복적 알고리즘으로 최적화하면 메모리 갱신 규칙이 나오고, 시퀀스 모델은 inner loop(메모리 파라미터 최적화)와 outer loop(나머지 파라미터 최적화)의 두 수준을 갖는 메타 in-context learner다.

> 각주: 여기서 "선형"은 빠른 학습·추론 절차를 가리키며 recurrence 공식을 뜻하지 않는다. Titans, Yaad, Moneta, Memora, TTT 등은 비선형 recurrence 기반이지만 학습·추론이 빠르다.

**B.1 예시.** 선형 attention은 내적 유사도 $\tilde\ell_t := \langle M_{t-1}k_t, v_t\rangle$의 gradient descent 최적화로 정의된다:

$$ M_t = M_{t-1} - \eta_t \nabla\langle M_{t-1}k_t, v_t\rangle = M_{t-1} + \eta_t v_t k_t^\top. \tag{45, 46} $$

회귀 손실을 쓰면 DeltaNet을 얻는다:

$$ M_t = M_{t-1} - \eta_t \nabla\|M_t k_t - v_t\|_2^2 = \left(I - \eta_t k_t k_t^\top\right)M_{t-1} + v_t k_t^\top. \tag{47} $$

### 부록 C. 뒷받침 증명 (Supporting Proofs)

**명제 1 증명.** $K = [k_1 \cdots k_m] \in \mathbb{R}^{d_k \times m}$, $V = [v_1 \cdots v_m] \in \mathbb{R}^{d_v \times m}$로 두면 문제는 Frobenius norm $\|MK - V\|_2^2$ 최소화가 되고, 정확한 기억은 $MK = V$를 요구한다. 벡터화하면 $(K^\top \otimes I_{d_v})\text{vec}(M) = \text{vec}(V)$로 $md_v$개 방정식, $d_k d_v$개 미지수다. key가 선형 독립이면 $\text{rank}(K) = m$이므로 시스템 행렬은 완전 행 랭크 $md_v$를 갖고, 가해성은 $md_v \le d_k d_v$, 즉 $m \le d_k$를 요구한다. $m \le d_k$이고 $K$가 완전 열 랭크이면 Moore-Penrose 유사역행렬로 정확한 보간해 $M^* = VK^\top$를 구성할 수 있어 상한이 tight하다. 또한 스텝 $0 < \eta < 2/\lambda_{\max}(KK^\top)$의 full-batch gradient descent는 최소 노름 보간해 $M^\dagger = VK^\top$로 수렴한다(gradient descent의 암묵적 편향). 같은 랭크 제약이 선형·multi-head attention의 "low-rank bottleneck"을 지배한다. $\square$

**정리 1 증명(스케치).** ReLU MLP는 조각별 아핀이다. 고정된 활성 패턴에서 $M(\cdot) = A\cdot + B$, $A = W^{(L_M)}D^{(L_M-1)}W^{(L_M-1)}\cdots D^{(1)}W^{(1)}$(각 $D^{(\ell)}$은 활성 유닛을 고르는 $\{0,1\}$ 대각 행렬)이다. 모든 key가 같은 선형 영역에 있으면(작은 섭동 후 일반적으로 성립) $M$은 단일 아핀 변환이다. 정확한 기억은 $A\mathcal{K} = \mathcal{V}$를 뜻하므로 $m = \text{rank}(\mathcal{K}) \le \min\{\text{rank}(A), d_k\}$이다. $A$의 랭크는 각 경로의 최소 폭과 즉각 입력 차원의 곱으로 제한되어 $\text{rank}(A) \le \sum_{i=1}^{L_M} \min_{j\ge i}\{d_h^{(j)}\}\,d_h^{(i)} = O\!\left(d_k d_v \sum_{i=1}^{L_M} \min_{j\ge i}\{d_h^{(j)}\}\,d_h^{(i+1)}\right)$이다. $\square$

**명제 2 증명.** 차수 정확히 $\ell$인 $d_k$변수 단항식의 수는 stars-and-bars로 $\binom{d_k + \ell - 1}{\ell}$이고, $\ell = 0$부터 $p$까지 합하면 hockey-stick 항등식으로 $D = \binom{d_k + p}{p}$이다. $\Phi = [\phi_p(k_1) \cdots \phi_p(k_m)] \in \mathbb{R}^{D \times m}$로 두면 정확한 기억은 $M\Phi = V$를 요구하는데, 랭크의 sub-multiplicativity로 $\text{rank}(M\Phi) \le \text{rank}(\Phi) \le D$이다. target이 선형 독립이면($V = [e_1, \dots, e_m]$) $\text{rank}(V) = m$이고, $m > D$이면 시스템이 풀리지 않는다. 따라서 어떤 optimizer도 $D = \binom{d_k+p}{p}$개를 초과해 기억할 수 없고, 고정 $p$에 대해 $\binom{d_k+p}{p} = \Theta(d_k^p)$이므로 용량은 $O(d_k^p)$로 상한이 정해진다. $\square$

### 부록 D. 모든 구조의 상세 정식화 (Detailed Formulations)

- **D.1 DLA:** 내적 유사도 $\min_M \langle M(k_t), v_t\rangle$를 gradient descent로 최적화, $M_t = \alpha_t M_{t-1} - \eta_t\nabla\ell(M_{t-1}; k_t, v_t)$; 선형 메모리에서 $W_t = \alpha_t W_{t-1} + v_t k_t^\top$(gated 선형 attention).
- **D.2 SWLA:** sliding window 목적함수 $\min_M \sum_{i=t-c+1}^{t}\langle M_{t-1}(k_i), v_i\rangle$; 선형 메모리에서 $M_t = \alpha_t M_{t-1} - \sum_{i=t-c+1}^{t}\eta_i^{(t)} v_i k_i^\top$.
- **D.3 OmegaNet:** 내적 대신 $\ell_2$ 회귀를 써서 $M_t = \alpha_t M_{t-1} - \sum_{i=t-c+1}^{t}\eta_i^{(t)}\nabla\|M_{t-1}(\phi(k_i)) - v_i\|_2^2$($\phi$는 다항식 feature map).
- **D.4 Atlas:** OmegaNet과 같은 내부 목적함수를 Muon(가중치 감쇠 포함)으로 최적화: $M_t = \alpha_t M_{t-1} + \text{Newton-schulz5}(S_t)$, $S_t = \theta_t S_{t-1} - \sum_{i=t-c+1}^{t}\eta_i^{(t)}\nabla\|M_{t-1}(\phi(k_i)) - v_i\|_2^2$.

### 부록 E. 실험 세부 (Experimental Details)
