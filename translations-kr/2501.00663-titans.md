## 초록 (Abstract)

지난 십수 년 동안, recurrent 모델과 attention을 어떻게 하면 효과적으로 활용할 수 있는가에 대한 방대한 연구가 이어져 왔다. recurrent 모델은 데이터를 고정 크기의 메모리(이른바 hidden state)로 압축하려 하는 반면, attention은 전체 context window를 훑어보며 모든 토큰 사이의 직접적 의존 관계를 포착한다. 그러나 이렇게 의존 관계를 더 정확하게 모델링하는 대가는 제곱(quadratic) 비용이며, 그 때문에 모델이 다룰 수 있는 context 길이가 고정된 범위로 제한된다.

우리는 과거 context를 기억하도록 학습하는 새로운 **neural long-term memory module**을 제안한다. 이 메모리는 attention이 현재 context에 주의를 기울이면서도 오래된 과거 정보를 함께 활용하도록 돕는다. 이 neural memory는 학습을 빠르게 병렬화할 수 있으면서도 추론(inference) 역시 빠르게 유지한다는 장점이 있다. 메모리의 관점에서 보면, attention은 context가 제한되어 있는 대신 의존 관계를 정확히 모델링하므로 **short-term memory**처럼 작동하고, neural memory는 데이터를 기억하는 능력 덕분에 **long-term의, 더 지속적인 memory**로 작동한다. 이 두 모듈을 바탕으로 우리는 **Titans**라는 새로운 아키텍처 계열을 소개하고, 메모리를 아키텍처에 효과적으로 통합하는 세 가지 변형을 제시한다. language modeling, common-sense reasoning, genomics, time series 과제에 대한 실험 결과는 Titans가 Transformer 및 최신 linear recurrent 모델보다 더 효과적임을 보여 준다. 나아가 Titans는 2M 이상의 context window 크기까지 확장되면서도, needle-in-haystack 과제에서 baseline보다 높은 정확도를 유지한다.

## 1 서론 (Introduction)

> "기억의 진정한 기예는 곧 주의의 기예다!" — Samuel Johnson, 1787

순수 attention 기반 아키텍처인 Transformer는 in-context learning 능력과 대규모 학습 능력 덕분에 sequence modeling에서 최첨단 모델로 확고히 자리 잡았다. Transformer의 핵심 구성 요소인 attention 모듈은 associative memory 블록처럼 작동한다. 즉 key-value 연관을 저장하도록 학습하고, query(검색 신호)와 key(context) 사이의 쌍별 유사도를 계산해 이를 되찾아 온다. 설계상 Transformer의 출력은 오직 현재 context window 안 토큰들의 직접적 의존 관계에만 조건화된다. 그러나 이렇게 의존 관계를 정확히 모델링하는 대가로 context 길이에 대해 **제곱 시간·메모리 복잡도**가 든다. language modeling, video understanding, long-term time series forecasting 같은 복잡한 실제 과제에서는 context window가 극단적으로 커질 수 있어, 이런 downstream 과제에서 Transformer의 적용성이 제약된다.

Transformer의 확장성 문제를 극복하기 위해, 최근 연구들은 attention의 softmax를 kernel 함수로 대체하는 다양한 **linear Transformer** 변형을 설계했고(§2.1 참조), 이로써 메모리 소비를 크게 줄였다. 하지만 효율성과 긴 context 확장성에도 불구하고, linear Transformer는 Transformer만큼 경쟁력 있는 성능을 보이지 못한다. kernel trick이 모델을 linear recurrent network로 만들어 데이터를 matrix 값 상태로 압축하기 때문이다. 여기에는 모순적인 사실이 있다. 한편으로 우리는 확장성과 효율성(선형 대 제곱 복잡도)을 위해 이런 linear 모델을 쓰는데, 그 이점은 아주 긴 context에서 두드러진다. 다른 한편으로, 아주 긴 context는 작은 vector 값이나 matrix 값 상태로는 제대로 압축될 수 없다.

효율성 문제를 넘어서, Hopfield Network부터 LSTM, Transformer에 이르는 대부분의 기존 아키텍처는 일반화(generalization), 길이 외삽(length extrapolation), 추론(reasoning)에서 어려움을 겪는다. 이들은 인간 뇌에서 영감을 받았음에도 각각 다음을 놓치고 있다. (1) short-term memory, long-term memory, meta-memory, 현재 context에 주의 기울이기 등 학습 과정에 필수적인 요소, (2) 이 요소들이 독립적으로 작동할 수 있는 상호 연결된 시스템이라는 점, (3) 데이터로부터 능동적으로 학습하고 과거의 추상을 기억하는 능력. 우리는 효과적인 학습 패러다임이라면 인간의 뇌처럼 서로 구별되면서도 연결된 모듈들이 있어야 하고, 각 모듈이 학습 과정의 한 요소를 담당해야 한다고 주장한다.

### 메모리 관점 (Memory Perspective)

메모리는 근본적인 정신 과정이며 인간 학습에서 떼어 낼 수 없는 요소다. 제대로 기능하는 메모리 시스템이 없다면 인간과 동물은 기본 반사와 정형화된 행동에 갇힐 것이다. 그런 까닭에 메모리는 Hopfield Network, LSTM, Transformer 등 기계학습의 여러 선구적 연구에 영감을 주었다.

신경심리학 문헌의 통상적 정의를 빌리면, 대부분의 기존 아키텍처는 메모리를 입력이 일으키는 신경 갱신으로 보고, 학습을 어떤 목적 아래 효과적이고 유용한 메모리를 획득하는 과정으로 정의한다. 이 관점에서 RNN은 vector 값 메모리 모듈 $\mathcal{M}$(hidden state)을 갖는 모델로 정의된다. 시각 $t$에 새 입력 $x_t$가 주어지면 모델은 (1) 함수 $f(\mathcal{M}_{t-1}, x_t)$로 메모리를 갱신하고(압축을 동반), (2) 함수 $g(\mathcal{M}_t, x_t)$로 입력에 해당하는 메모리를 되찾는다. 마찬가지로 Transformer도 커지는 메모리를 가진 아키텍처로 볼 수 있다. key/value 행렬 쌍이 모델의 메모리 역할을 하며, 모델은 (1) key와 value를 메모리에 덧붙여(압축 없이) 갱신하고, (2) query와 key의 유사도를 찾아 value에 가중치를 부여해 출력을 만든다.

이 관점은 기존 패러다임과 그 결정적 차이를 이해하고 더 효과적인 아키텍처를 설계하는 데 도움을 준다. 예를 들어 Transformer와 linear Transformer의 주된 차이는 메모리 구조와 메모리 갱신 방식에 있다. linear Transformer는 과거 데이터를 고정 크기 matrix 값 메모리로 압축하는 반면, Transformer는(context 길이 안에서) 모든 과거 데이터를 압축 없이 보관한다. linear Transformer와 linear RNN(state space model 포함) 모두 메모리 갱신 단계에서 정보를 압축하지만, 결정적 차이는 메모리의 구조에 있다. linear RNN은 vector 값 메모리를, linear Transformer는 matrix 값 메모리를 쓴다. 이런 관점은 다음 질문으로 이어진다. **(Q1) 좋은 메모리 구조는 무엇인가? (Q2) 적절한 메모리 갱신 방식은 무엇인가? (Q3) 좋은 메모리 검색 과정은 무엇인가?**

인간의 기억을 다시 보면, 그것은 단일한 과정도 단일한 기능도 아니다. 기억은 여러 시스템의 연합체이며 short-term, working, long-term memory가 각기 다른 신경 구조로 다른 기능을 수행하고 저마다 독립적으로 작동할 수 있다. 이 사실은 다음 질문을 던지게 한다. **(Q4) 서로 연결된 여러 메모리 모듈을 통합하는 효율적 아키텍처를 어떻게 설계할 것인가.** 끝으로, 기억을 저장한다는 것은 과거의 추상을 부호화해 저장하는 신경 과정이다. 매개변수가 데이터를 선형적으로 부호화하는 단일 vector나 matrix로 긴 과거를 저장하기에 충분하다고 보는 것은 지나친 단순화일 수 있다. **(Q5) 긴 과거를 효과적으로 저장·기억하려면 deep memory 모듈이 필요한가?**

### 기여와 로드맵 (Contributions and Roadmap)

이 논문은 위 다섯 질문에 답하기 위해, test time에 기억을 효율적·효과적으로 학습하는 long-term neural memory module을 설계하고, 이를 아키텍처에 통합하는 방법을 논한다.

**Neural Memory (§3).** 우리는 (meta in-context 모델로서) test time에 데이터를 자신의 매개변수로 기억·저장하는 법을 학습하는 (deep) neural long-term memory를 제시한다. 인간의 long-term memory 시스템에서 영감을 받아, 기대를 위배하는(즉 놀라운) 사건이 더 잘 기억되도록 설계한다. 이를 위해 입력의 놀라움(surprise)을 associative memory loss에 대한 신경망의 gradient로 측정한다(§3.1). 제한된 메모리를 더 잘 다루기 위해, 메모리 크기와 데이터 놀라움의 비율을 고려하는 감쇠(decay) 메커니즘을 도입한다. 우리는 이 감쇠 메커니즘이 사실 최신 recurrent 모델의 forgetting 메커니즘을 일반화한 것임을 보인다. 흥미롭게도 이 메커니즘은 **momentum과 weight decay를 동반한 mini-batch gradient descent로 meta 신경망을 최적화하는 것과 동치**임을 알 수 있다. mini-batch gradient descent를 tensorize해 matmul 연산을 더 쓰는 기법 위에서, 우리는 deep neural long-term memory를 빠르게 병렬 학습하는 알고리즘을 제시한다.

**Titans 아키텍처 (§4).** long-term neural memory를 설계한 뒤, 남는 문제는 이 메모리를 딥러닝 아키텍처에 어떻게 효과적으로 통합하느냐다. 우리는 세 개의 hyper-head로 구성된 딥 모델 계열인 Titans를 제시한다. (1) **Core**: short-term memory로 이루어지며 데이터 처리의 주된 흐름을 담당한다(제한된 window 크기의 attention 사용). (2) **Long-term Memory**: 긴 과거를 저장·기억하는 우리의 neural long-term memory 모듈. (3) **Persistent Memory**: 과제에 관한 지식을 부호화하는, 학습 가능하지만 데이터에 무관한 매개변수 집합. 개념 증명으로 우리는 메모리를 (i) context로, (ii) layer로, (iii) gated branch로 통합하는 세 가지 Titans 변형을 제시한다.

**실험 결과 (§5).** language modeling, common-sense reasoning, recall 집약 과제, needle-in-haystack, time series forecasting, DNA modeling에서 평가한다. Titans는 포괄적 벤치마크에서 모든 최신 recurrent 모델과 그 hybrid 변형(sliding-window attention 결합)을 능가한다. 또한 같은 context window의 Transformer를 능가하고, 전체 context를 쓰는 Transformer와도 경쟁력 있는 성능을 보인다. 그러면서도 Transformer와 달리 2M 이상의 context window로 확장된다.

## 2 준비 (Preliminaries)

이 절에서는 논문 전반에서 쓰는 표기와 배경 개념을 논한다. 입력을 $x \in \mathbb{R}^{N \times d_{in}}$, neural memory 모듈을 $\mathcal{M}$, attention의 query/key/value를 $Q, K, V$, attention mask를 $\mathbf{M}$으로 둔다. sequence를 분할할 때 $i$번째 segment는 $S^{(i)}$로 쓴다. 아래첨자는 행렬·벡터·segment의 특정 원소를 가리키는 데 남용해 쓰며, 예컨대 $S^{(i)}_j$는 $i$번째 segment의 $j$번째 토큰이다. 예외는 아래첨자 $t$로, 이는 시간에 대한 recurrence 혹은 시각 $t$에서의 신경망 상태를 가리키는 데 예약해 둔다. 신경망 $\mathcal{N}$과 데이터 표본 $x$에 대해, $\mathcal{N}(x)$는 가중치 조정을 **동반하는** forward pass를, $\mathcal{N}^*(x)$는 가중치 조정을 **동반하지 않는** forward pass를 가리킨다. 또 $\mathcal{N}^{(k)}$는 신경망의 $k$번째 layer를 뜻한다.

### 2.1 배경 (Backgrounds)

**Attention.** 입력 $x \in \mathbb{R}^{N \times d_{in}}$이 주어지면, causal attention은 입력에 의존하는 key/value/query 행렬에 대한 softmax로 출력 $y \in \mathbb{R}^{N \times d_{in}}$을 계산한다.

$$Q = xW_Q, \quad K = xW_K, \quad V = xW_V \tag{1}$$

$$y_i = \frac{\sum_{j=1}^{i} \exp\!\big(Q_i^\top K_j / \sqrt{d_{in}}\big) V_j}{\sum_{\ell=1}^{i} \exp\!\big(Q_i^\top K_\ell / \sqrt{d_{in}}\big)} \tag{2}$$

여기서 $W_Q, W_K, W_V \in \mathbb{R}^{d_{in} \times d_{in}}$은 학습 가능한 매개변수다. 이 식은 각 query가 앞선 모든 key와의 유사도로 value들을 가중 평균한다는 뜻이다. Transformer는 출력을 계산하는 데 최소 $N \times d$ 연산이 필요해, 긴 sequence에서 메모리 소비가 크고 throughput이 낮다.

**Efficient Attention.** softmax attention의 메모리·throughput을 개선하려는 연구는 I/O를 고려한 구현, attention 행렬의 희소화, softmax 근사, kernel 기반(linear) attention 등으로 나뉜다. 여기서는 linear attention에 집중한다. 표준 attention의 softmax를 $\phi(x, y) = \phi(x)\phi(y)$를 만족하는 kernel 함수 $\phi(\cdot, \cdot)$로 대체하면 attention은 다음과 같이 쓸 수 있다.

$$y_i = \frac{\phi(Q_i)^\top \sum_{j=1}^{i} \phi(K_j) V_j}{\phi(Q_i)^\top \sum_{\ell=1}^{i} \phi(K_\ell)} \tag{3}$$

이 식은 $\sum_{j} \phi(K_j)$와 $\sum_{\ell} \phi(K_\ell)$ 항이 매 단계 재사용되므로 throughput이 높아진다는 뜻이다. kernel을 항등으로 택하면 위 식을 recurrent 형태로도 쓸 수 있다.

$$\mathcal{M}_t = \mathcal{M}_{t-1} + K_t^\top V_t, \tag{4}$$
$$y_t = Q_t \mathcal{M}_t \tag{5}$$

이는 linear attention이 효율적 추론을 가능케 함을 보여 준다.

**최신 linear 모델과 그 메모리 관점.** 학습을 유용한 메모리를 획득하는 과정으로 정의하면, RNN의 hidden state는 모델이 정보를 압축해 넣는 메모리 단위로 볼 수 있다. 일반적 RNN에서 hidden state는 메모리 단위이고 recurrence 과정은 읽기·쓰기 연산으로 나뉜다. $x \in \mathbb{R}^{N \times d_{in}}$을 입력, $\mathcal{M} \in \mathbb{R}^d$를 메모리 단위, $y \in \mathbb{R}^{d_{in}}$을 출력이라 하면 일반적 RNN은 다음과 같다.

$$\mathcal{M}_t = f(\mathcal{M}_{t-1}, x_t), \qquad \text{(쓰기 연산)} \tag{6}$$
$$y_t = g(\mathcal{M}_t, x_t) \qquad \text{(읽기 연산)} \tag{7}$$

이 관점에서 linear Transformer의 recurrence(식 4)는 key와 value $(K_t, V_t)$를 matrix 값 메모리 $\mathcal{M}_t$에 덧셈으로 압축·기록하는 것과 동치다. 이 덧셈적 성질 때문에 긴 context에서는 메모리 오버플로가 일어나 성능이 크게 손상된다. 이를 해결하려는 두 방향이 있다. (1) **forget 메커니즘 추가**: GLA, LRU, Griffin, xLSTM, Mamba2처럼 필요할 때 메모리를 지울 수 있는 적응적(데이터 의존) forget gate를 도입한다. (2) **쓰기 연산 개선**: 전통적 recurrent 모델의 덧셈적 쓰기를 극복하기 위해 Widrow와 Hoff는 Delta Rule을 제시했는데, key-value 쌍을 더하기 전에 그 과거 value를 먼저 제거한다. DeltaNet은 이를 sequence 길이에 대해 병렬화했고, Gated DeltaNet은 여기에 forget gate를 추가했다.

**Memory 모듈.** 메모리는 늘 신경망 설계의 핵심이었다. 선형 layer를 key-value(associative) 메모리 시스템으로 보는 발상은 fast weight program으로 거슬러 올라가며, 여기서 동적 fast program이 RNN에 쓰기 가능한 메모리로 통합된다. Hebbian 규칙과 delta 규칙이 가장 널리 쓰인 학습 규칙이다. 다만 이런 모델들은 모두 **momentary surprise(순간적 놀라움)**에 기반해 sequence의 토큰 흐름(token flow)을 놓치고, 대부분 forget gate가 없어 메모리 관리가 부실하다. 최신 모델과 우리 아키텍처의 연결은 부록 C에서, 추가 관련 연구는 부록 A에서 논한다.

## 3 Test Time에 기억하기를 학습하기 (Learning to Memorize at Test Time)

long-term memory의 부재를 극복하고 모델이 정보를 학습·망각·검색하도록, 이 절에서는 test time에 기억하기를 학습하는 meta 모델인 neural long-term memory module을 제시한다. §3.1에서 동기와 설계를, §3.2에서 빠른 병렬 학습을, §3.3에서 persistent memory 증강을 다룬다.

### 3.1 Long-term Memory

long-term memory 모듈을 설계하려면 과거 이력의 추상을 자신의 매개변수로 부호화할 수 있는 모델이 필요하다. LLM이 학습 데이터를 기억한다는 사실이 그 예다. 그러나 memorization은 대개 바람직하지 않은 현상으로 알려져 왔다. 일반화를 제한하고, 프라이버시 우려를 낳으며, test time 성능을 떨어뜨린다. 게다가 test 데이터가 분포 밖(out-of-distribution)일 수 있으므로 학습 데이터를 외운 것이 test time에 도움이 되지 않을 수 있다. 우리는 **test time에 데이터를 기억·망각하는 법을 학습하는 online meta-model**이 필요하다고 주장한다. 이 설정에서 모델은 memorization이 가능한 함수를 학습하되 학습 데이터에 과적합하지 않아, test time에 더 나은 일반화를 얻는다.

**학습 과정과 surprise 지표.** long-term memory 학습의 핵심 발상은 이를 online learning 문제로 다루어, 과거 정보 $x_1, \dots, x_{t-1}$을 long-term neural memory 모듈 $\mathcal{M}_t$의 매개변수로 압축하는 것이다. 기대를 위배하는(놀라운) 사건이 더 잘 기억된다는 인간 기억의 특성에서 영감을 받아, 모델의 놀라움을 **입력에 대한 gradient**로 단순하게 정의한다. gradient가 클수록 입력이 과거 데이터와 더 다르다는 뜻이다. 이 surprise 점수로 메모리를 다음과 같이 갱신한다.

$$\mathcal{M}_t = \mathcal{M}_{t-1} - \theta_t \underbrace{\nabla \ell(\mathcal{M}_{t-1}; x_t)}_{\text{Surprise}} \tag{8}$$

이 식은 현재 토큰이 저장된 내용을 얼마나 위배하는지를 gradient로 재고, 그만큼 메모리를 갱신한다는 뜻이다. 그러나 이 surprise 지표만으로는 큰 놀라움 직후에 오는 중요한 정보를 놓칠 수 있다. 여러 번 놀라운 단계를 거치면 gradient가 극단적으로 작아져 평평한 영역(국소 최소)에 갇히고 sequence의 일부 정보를 놓치기 때문이다. 인간 기억의 관점에서, 어떤 사건은 기억할 만해도 긴 시간 내내 우리를 놀라게 하지는 않는다. 처음 순간이 충분히 놀라워 긴 시간대 내내 주의를 끌고, 그 시간대 전체를 기억하게 만드는 것이다. 이를 개선하기 위해 surprise를 (1) 아주 최근 과거의 놀라움인 **past surprise**와 (2) 새로 들어오는 데이터의 놀라움인 **momentary surprise**로 나눈다.

$$\mathcal{M}_t = \mathcal{M}_{t-1} + S_t, \tag{9}$$
$$S_t = \eta_t \underbrace{S_{t-1}}_{\text{Past Surprise}} - \theta_t \underbrace{\nabla \ell(\mathcal{M}_{t-1}; x_t)}_{\text{Momentary Surprise}} \tag{10}$$

이 식은 **momentum을 동반한 gradient descent**와 유사하며, $S_t$가 momentum 항이다. 즉 momentum은 시간(sequence 길이)에 걸친 **놀라움의 기억** 역할을 한다. $\eta_t$는 놀라움이 시간에 따라 어떻게 감쇠하는지를 제어하는 데이터 의존 surprise decay($x_t$의 함수)이고, $\theta_t$는 momentary surprise를 최종 surprise 지표에 얼마나 반영할지를 데이터 의존적으로 제어한다. 이 데이터 의존성이 특히 중요하다. 이전 토큰의 놀라움이 다음 토큰의 놀라움에 영향을 주는 것은 대개 모든 토큰이 서로 관련되어 같은 context에 있을 때만 타당하기 때문이다. 따라서 데이터 의존적 $\eta$는 (1) $\eta_t \to 0$으로 지난 놀라움을 무시하거나(context 전환 가능성), (2) $\eta_t \to 1$로 지난 놀라움을 온전히 반영할지(최근 토큰과 강하게 관련)를 제어할 수 있다.

**목적함수 (Objective).** 위 surprise 지표는 손실 함수 $\ell(\cdot;\cdot)$에 기반하며, 이것이 메모리가 test time에 학습해 수행하는 목적이다. 즉 메모리는 손실 $\ell$에 따라 함수를 학습하는 meta 모델이다. 이 연구에서는 과거 데이터를 key-value 쌍으로 저장하는 **associative memory**에 집중한다. $x_t$가 주어지면 두 선형 layer로 key와 value를 사영한다.

$$k_t = x_t W_K, \quad v_t = x_t W_V, \tag{11}$$

여기서 $W_K, W_V \in \mathbb{R}^{d_{in} \times d_{in}}$이다. 메모리가 key와 value의 연관을 학습하도록 손실을 다음과 같이 정의한다.

$$\ell(\mathcal{M}_{t-1}; x_t) = \|\mathcal{M}_{t-1}(k_t) - v_t\|_2^2 \tag{12}$$

이 손실을 meta 모델(메모리)의 **inner-loop**에서 최적화함으로써, 모델은 test time에 key와 value의 매핑을 기억하는 법을 학습한다. meta-learning 모델처럼 메모리의 학습은 inner-loop에서 이루어지므로 $W_K, W_V$는 위 손실의 **하이퍼파라미터**다. 즉 inner-loop에서는 $\mathcal{M}$의 가중치를, **outer-loop**에서는 아키텍처의 나머지 매개변수를 최적화한다.

**Forgetting 메커니즘.** 수백만 토큰 같은 아주 긴 sequence를 다룰 때는, 깊거나 아주 큰 matrix 값 메모리라도 어떤 과거 정보를 잊어야 할지 관리하는 것이 결정적이다. 이를 위해 더 이상 필요 없는 정보를 잊게 하는 적응적 forgetting 메커니즘을 도입해 갱신 규칙을 수정한다.

$$\mathcal{M}_t = (1 - \alpha_t)\mathcal{M}_{t-1} + S_t, \tag{13}$$
$$S_t = \eta_t S_{t-1} - \theta_t \nabla \ell(\mathcal{M}_{t-1}; x_t), \tag{14}$$

여기서 $\alpha_t \in [0, 1]$은 메모리를 유연하게 제어하는 gating이다. $\alpha_t \to 0$이면 과거 추상을 건드리지 않고 메모리를 갱신하고, $\alpha_t \to 1$이면 메모리 전체를 지운다. 이 weight decay 메커니즘은 최신 RNN의 gating 메커니즘과 밀접하게 관련된다. 정리하면, 전체 메모리 쓰기는 세 개의 스칼라가 토큰마다 gating되는 **momentum·weight decay를 동반한 mini-batch gradient descent 한 스텝**이다.

**Memory 아키텍처.** 이 논문에서는 $L_{\mathcal{M}} \ge 1$개 layer의 단순 MLP를 long-term memory의 아키텍처로 삼는다. 그 이유는 long-term memory의 설계 동기와 통합 방식을 명확히 하는 데 집중하기 위함이다. vector 값이나 matrix 값 메모리를 쓰면 메모리 모듈은 과거 데이터를 하나의 선(line)에 압축·적합시킨다. 즉 meta-learning/online-learning 관점에서 matrix 값 메모리 $\mathcal{M} = W \in \mathbb{R}^{d_{in} \times d_{in}}$을 쓰는 것은 $\ell(W_{t-1}; x_t) = \|W_{t-1} k_t - v_t\|_2^2$를 최적화하는 것과 동치인데, 이는 **online linear regression** 목적이므로 과거 데이터의 의존 관계가 선형이라고 가정한다. 반면 우리는 **deep memory 모듈**($L_{\mathcal{M}} \ge 2$)을 주장한다. 2개 이상 layer의 MLP가 선형 모델보다 엄밀히 더 표현력 있다는 이론적 결과에 부합하며, §5.5에서 deep memory가 실제로도 더 효과적임을 보인다.

**Memory 검색 (Retrieving a Memory).** 메모리로부터 어떻게 정보를 되찾는가? 우리는 가중치 갱신 없는 forward pass(추론)로 query에 해당하는 메모리를 검색한다. 입력 $x_t$에 선형 layer $W_Q$를 적용해 $q_t = x_t W_Q$를 얻고, 다음으로 해당 정보를 되찾는다.

$$y_t = \mathcal{M}^*(q_t) \tag{15}$$

이 식은 읽기가 메모리 가중치를 바꾸지 않는 순수 추론임을 뜻한다.

### 3.2 Long-term Memory 학습을 어떻게 병렬화할 것인가

앞에서 보았듯, long-term memory 모듈의 설계는 associative memory 손실 $\ell(\mathcal{M}_{t-1}; x_t) = \|\mathcal{M}_{t-1}(k_t) - v_t\|_2^2$를 momentum·weight decay를 동반한 gradient descent로 최적화하는 meta 모델 학습과 동치다. 따라서 이론상 long-term memory 학습에는 $O(N)$ FLOP이 든다($N$은 sequence 길이). 그러나 실제로는 학습을 병렬화하고 하드웨어 가속기(TPU, GPU)를 온전히 활용하기 위해 과정을 tensorize하고 matmul을 더 써야 한다.

이제 mini-batch gradient descent, 데이터 의존 learning rate, weight decay로 inner-loop 가중치를 계산하는 과정이 matmul과 sum만으로 재구성됨을 보인다. mini-batch gradient descent(상수 learning rate)로 최적화하는 모델의 forward pass가 matmul로 계산될 수 있다는 결과 위에서, sequence를 크기 $b \ge 1$의 chunk로 나누어 mini-batch gradient descent를 다음과 같이 쓴다.

$$\mathcal{M}_t = (1 - \alpha_t)\mathcal{M}_{t-1} - \theta_t \nabla \ell(\mathcal{M}_{t-1}; x_t) = \beta_t \mathcal{M}_0 - \sum_{i=1}^{t} \theta_i \frac{\beta_t}{\beta_i} \nabla \ell(\mathcal{M}_{t'}; x_i), \tag{16}$$

여기서 $t' = t - \mathrm{mod}(t, b)$이고 $\beta_i = \prod_{j=1}^{i}(1 - \alpha_j)$이다. 이 식은 chunk 안의 모든 gradient를 **chunk 시작 시점의 가중치** $\mathcal{M}_{t'}$에서 취한다는 뜻이다(순수 online GD 대신 mini-batch). 단순화를 위해 첫 chunk($t = b$, $t' = 0$)와 선형 메모리 $\mathcal{M}_t = W_t$ 경우를 보면, 손실을 이용해 다음을 얻는다.

$$\nabla \ell(W_0; x_t) = (W_0 x_t - x_t) x_t^\top \;\Rightarrow\; \sum_{i=1}^{b} \theta_i \frac{\beta_b}{\beta_i} \nabla \ell(W_0; x_i) = \Theta_b \mathbf{B}_b (W_0 X - X) X^\top, \tag{17}$$

여기서 $\Theta_b = \mathrm{diag}(\theta_1, \theta_2, \dots, \theta_b)$이고 $\mathbf{B}_b$는 $\beta_b / \beta_i$들로 유사하게 정의된 대각 행렬이다. 이 식은 chunk 안 모든 gradient가 같은 고정 가중치를 쓰므로 하나의 batched matmul로 동시에 계산됨을 뜻한다. 모든 $\Theta_b^k, \mathbf{B}_b^k$를 한꺼번에 저장할 필요 없이 chunk별로만 저장하므로 메모리를 덜 쓴다. MLP 메모리($L_{\mathcal{M}} \ge 2$)의 경우도 유사하다.

**momentum 항의 병렬화.** momentum 항을 살펴보면,

$$S_t = \eta_t S_{t-1} - \theta_t u_t, \tag{18}$$

여기서 $u_t = \nabla \ell(\mathcal{M}_{t'}; x_t)$이다. 모든 $u_t$는 동시에 계산할 수 있으므로 식 (18)은 $u_t$를 입력, $S_t$를 hidden state, $\eta_t$를 입력 의존 전이값으로 갖는 **1차 선형 recurrence**다. 따라서 **parallel associative scan**으로 chunk 안 모든 $S_t$를 계산할 수 있다.

**매개변수를 chunk의 함수로.** $\alpha_t, \theta_t, \eta_t$를 토큰 $x_t$의 함수 대신 **chunk의 함수**로 만들 수도 있다. 표현력은 잃지만 학습을 더 빠르게 할 수 있다. 이 경우 각 chunk 안에서 $\alpha, \theta, \eta$가 같은 값을 쓰므로, 식 (17)에서 $\Theta$를 단일 스칼라로 저장할 수 있다. $\eta, \theta$가 chunk 안에서 학습 가능하되 시불변이면 식 (18)은 **선형 시불변(LTI) 시스템**이 되어 global convolution으로 계산된다. 우리 실험에서는 이 매개변수를 토큰의 함수로 두지만, 이런 단순화는 더 큰 모델을 효율적으로 학습하는 향후 연구 대상이 될 수 있다.

### 3.3 Persistent Memory

우리의 long-term memory는 출력이 전적으로 context에 의존하므로 **contextual memory**로도 볼 수 있다. 그래서 우리는 long-term memory 외에, 과제 관련 메모리 역할을 하는 학습 가능하지만 입력에 무관한 매개변수 집합도 함께 쓴다. 이런 메모리는 문헌에서 persistent 혹은 meta-memory로 불린다. $N_p \ge 1$에 대해 학습 가능한 매개변수 $P = [p_1\ p_2\ \dots\ p_{N_p}]$를 sequence 앞에 붙인다.

$$x_{new} = [p_1\ p_2\ \dots\ p_{N_p}] \,\|\, x, \tag{19}$$

여기서 $\|$는 연결(concatenation)이다. persistent memory의 동기를 세 관점에서 논한다.

**메모리 관점.** neural long-term memory는 모든 매개변수가 입력 의존적인 contextual memory다. 효과적 메모리 시스템은 과제 지식의 추상을 저장할 **입력 무관 매개변수**도 필요로 한다. 과제를 익힌다는 것은 그 과제를 어떻게 수행하는지에 대한 지식을 기억하는 일이며, 이 매개변수가 그 지식을 담당한다.

**Feedforward Network 관점.** Transformer의 attention 뒤 fully-connected layer는 데이터 무관 매개변수를 가진 attention 가중치와 유사함이 알려져 있다. Sukhbaatar 등은 fully-connected layer의 ReLU를 Softmax로 바꾸면 attention과 비슷한, 데이터 무관 가중치가 나옴을 보였다.

$$FFN(x) = W_V\, \mathrm{Softmax}(W_K x) \tag{20}$$

여기서 $W_K, W_V$는 입력 무관일 때 attention의 $K, V$ 행렬처럼 작동한다. persistent memory 가중치도 같은 기능을 기대하는데, 이를 sequence 앞부분에 두면 입력 무관 attention 가중치를 갖게 된다.

**기술적 관점.** causal mask를 쓴 attention은 sequence 초기 토큰에 대한 암묵적 편향이 있어 초기 토큰에 거의 항상 높은 attention 가중치를 부여하고, 이는 성능을 손상시킨다. sequence 앞의 학습 가능한 매개변수는 attention 가중치를 더 효과적으로 재분배해 이런 효과(attention sink)를 완화한다.

## 4 메모리를 어떻게 통합할 것인가 (How to Incorporate Memory?)

남은 중요한 질문은 설계한 neural memory를 딥러닝 아키텍처에 어떻게 효과적·효율적으로 통합하느냐다. 메모리 관점에서 Transformer의 $K, V$ 행렬 쌍은 associative memory 블록으로 해석되며, 정확한 의존 관계 모델링과 제한된 context window 때문에 **short-term memory**로 본다. 반면 데이터로부터 계속 학습해 가중치에 저장하는 neural memory는 **long-term memory** 역할을 할 수 있다. 이 절에서 세 가지 Titans 변형을 제안하며, 각 변형은 아주 긴 context에서 효율성과 효과성 사이의 절충을 보인다.

### 4.1 Memory as a Context (MAC)

첫 설계에서는 메모리를 현재 정보에 대한 **context**로 다룬다. 긴 sequence $x \in \mathbb{R}^{N \times d_{in}}$을 먼저 고정 크기 segment $S^{(i)}$($i = 1, \dots, N/C$)로 나눈다. 들어오는 segment $S^{(t)}$를 현재 context로, 그 이전 segment들을 과거 정보로 본다. segment $S^{(t)}$ 직전의 long-term memory 상태를 $\mathcal{M}_{t-1}$이라 하면, 입력 context를 query로 삼아 메모리에서 해당 정보를 되찾는다.

$$h_t = \mathcal{M}^*_{t-1}(q_t), \tag{21}$$

여기서 $q_t = S^{(t)} W_Q$이다. 이어 이 과거 정보와 persistent memory를 attention 모듈의 입력 sequence로 쓴다.

$$\tilde{S}^{(t)} = [p_1\ p_2\ \dots\ p_{N_p}] \,\|\, h_t \,\|\, S^{(t)}, \tag{22}$$
$$y_t = \mathrm{Attn}\big(\tilde{S}^{(t)}\big) \tag{23}$$

전체 sequence에 대한 attention 맵 구조는 그림 3a에 나온다. 그 다음 $y_t$로 다음 segment를 위한 long-term memory를 갱신하고 최종 출력을 만든다.

$$\mathcal{M}_t = \mathcal{M}_{t-1}(y_t), \tag{24}$$
$$o_t = y_t \otimes \mathcal{M}^*_t(y_t) \tag{25}$$

즉 $\mathcal{M}_{t-1}$의 가중치를 forward pass를 통해 갱신한다. 이 설계의 이점은 다음과 같다. (1) attention이 과거와 현재 context를 모두 가지므로, 현재 데이터에 대해 long-term memory 정보가 필요한지 판단할 수 있다. (2) attention은 long-term memory가 현재 context에서 **유용한 정보만** 저장하도록 돕는다. 각 segment의 모든 토큰이 유용하지는 않으며 전부 외우면 메모리 오버플로가 날 수 있으므로, attention이 어떤 정보가 유용한지 이해하도록 도와 메모리 용량을 더 잘 관리한다. (3) test time: (i) persistent memory 매개변수는 과제 지식을 부호화하므로 고정되고, (ii) attention 모듈 가중치는 in-context learner이며, (iii) long-term memory 모듈은 test time에도 여전히 학습(기억)한다. 즉 가중치가 긴 과거의 추상을 부호화하므로 test time에도 neural memory의 가중치를 갱신한다.

### 4.2 Gated Memory (MAG)

다음 변형에서는 한 branch에서 입력 데이터로 직접 long-term memory를 갱신하고, 다른 branch에서 sliding-window attention(SWA)을 쓴다.

$$\tilde{x} = [p_1\ p_2\ \dots\ p_{N_p}] \,\|\, x, \tag{26}$$
$$y = \text{SW-Attn}^*(\tilde{x}), \tag{27}$$
$$o = y \otimes \mathcal{M}(\tilde{x}), \tag{28}$$

여기서 $\text{SW-Attn}^*$는 prefix를 둔 sliding-window attention이다(그림 3b). 앞 설계와 달리 입력 데이터를 분할하지 않는다. $\mathcal{M}(\tilde{x})$는 sequence 토큰들에 대한 모든 recursion을 마친 뒤 메모리의 최종 출력을 가리킨다. $\otimes$는 임의의 비선형 gating일 수 있으며, 실험에서는 $y$와 $\mathcal{M}(\tilde{x})$를 학습 가능한 vector 값 가중치로 정규화하고 비선형 $\sigma(\cdot)$을 적용한 뒤 결합한다. 이 설계에서 sliding-window attention은 정밀한 short-term memory로, neural memory 모듈은 사그라드는(fading) long-term memory로 작동한다. 이는 구조가 서로 다른 head들을 가진 multi-head 아키텍처로도 볼 수 있다.

### 4.3 Memory as a Layer (MAL)

마지막 변형은 neural memory를 딥 신경망의 한 **layer**로 쓴다. 이 설계는 문헌에서 더 흔한 형태로, hybrid 모델이 recurrent 모델을 full 또는 sliding-window attention과 쌓는 방식이다. 입력 $x$에 대해,

$$\tilde{x} = [p_1\ p_2\ \dots\ p_{N_p}] \,\|\, x, \tag{29}$$
$$y = \mathcal{M}(\tilde{x}), \tag{30}$$
$$o = \text{SW-Attn}(y), \tag{31}$$

여기서 $\text{SW-Attn}$은 sliding-window attention이다. 이 설계의 주된 단점은 모델의 성능이 각 layer에 의해 제약되어 attention과 neural memory의 상보적 데이터 처리를 활용하지 못한다는 점이다. 실험에서는 H3와 유사한 아키텍처를 쓰되 sequence 모델을 neural memory 모듈(LMM)로 대체한다.

**Attention 없는 메모리.** 위에서 MAL을 LMM과 attention의 순차 결합으로 논했지만, 단순 변형으로 LMM을 attention 없는 sequence 모델로 다룰 수도 있다. 메모리 시스템의 각 부분은 다른 요소가 교란되어도 독립적으로 작동해야 하므로, long-term memory 모듈은 short-term memory(attention) 없이도 강력한 모델이어야 한다. 이 변형을 실험에서 **LMM** 또는 **Titans (LMM)**으로 부른다.

![그림 5: Memory as a Layer (MAL) 아키텍처. 여기서 memory layer는 attention 모듈에 앞서 과거와 현재 context를 압축하는 역할을 한다. 출처: 원저자, arXiv:2501.00663 Fig.5](/home/jimmy/repos/neural-memory-study/reffigs/2501.00663/figures/fig5.png)

### 4.4 아키텍처 세부 사항

간결한 서술을 위해 residual connection, 선형 layer gating, 정규화 같은 구현 세부는 본문에서 생략했다. 모든 블록에서 residual connection을 쓴다. query/key/value 계산에는 비선형 활성으로 SiLU$(\cdot)$를 쓰고, query와 key는 $\ell_2$-norm으로 정규화한다.

**Convolution.** 최신 linear recurrent 모델을 따라, query·key·value 사영 뒤에 각각 1D depthwise-separable convolution layer를 넣는다. 성능에 큰 영향은 없으나 개선을 보였고 계산적으로도 효율적이다.

**Gating.** 최종 출력 사영 전에 정규화와 선형 layer gating을 쓴다.

**정리 4.1.** Transformer, 대각 linear recurrent 모델, DeltaNet은 모두 $TC^0$에 제한되지만, Titans는 $TC^0$를 넘어서는 문제를 풀 수 있다. 즉 state tracking 과제에서 Titans는 Transformer와 대부분의 최신 linear recurrent 모델보다 이론적으로 더 표현력이 크다.

### 5.3 Needle in a Haystack

모델을 더 긴 context window로 확장한다고 해서 아주 긴 sequence에서 효과적이라는 뜻은 아니다. needle-in-a-haystack(NIAH) 과제는 모델의 실제 유효 context 길이를 재도록 설계되었다. 긴 방해 텍스트("haystack") 속에서 한 조각 정보("needle")를 되찾는 능력을 본다. RULER 벤치마크의 Single NIAH(S-NIAH)를 써서 길이 2K/4K/8K/16K에서 평가한다(표 2). neural memory 모듈이 세 과제 모두에서 최고 성능을 낸다. 세 가지 핵심 차이 덕분이다. (1) TTT 대비, momentum과 forgetting(weight decay)으로 메모리 용량을 더 잘 관리하므로 길이가 늘어도 성능이 떨어지지 않고 일관된 추세를 보인다. (2) Mamba2 대비, deep 비선형 메모리를 가져 메모리 관리가 낫다. 또 Mamba2는 메모리를 제거할 수 없어 길이가 늘면 성능이 크게 떨어진다. (3) DeltaNet 대비, DeltaNet은 delta rule로 메모리를 대체할 수는 있으나 지울(erase) 수는 없어 forgetting이 없다. Titans 변형들은 동등하거나 더 나은 결과를 내며, 최고는 MAC다.

### 5.4 BABILong 벤치마크

앞 절은 needle 하나만 되찾는 단순 NIAH였다. 아주 긴 sequence에서의 진짜 이점을 보기 위해, 이 절에서는 극단적으로 긴 문서에 흩어진 사실들을 가로질러 추론해야 하는 더 어려운 BABILong 벤치마크를 쓴다. 원 실험 설정과 학습 절차를 따르며 두 설정을 둔다. (1) 대규모 사전학습 모델을 쓰는 **few-shot** 설정, (2) MAC 변형을 fine-tune해 다른 fine-tune baseline과 비교하는 **fine-tuning** 설정.

few-shot 결과(그림 6a)에서 Titans는 모든 baseline — Mamba-2.8B, RWKV-6-7B, RecurrentGemma-9B, Gemma-9B, Llama3.1-8B, GPT-4, GPT-4o-mini — 을 능가한다. 이는 Titans (MAC)가 baseline보다 훨씬 적은 매개변수를 가지면서 이룬 결과다.

fine-tuning 설정에서는 작은 Titans (MAC)를 (i) 거의 같은 규모의 작은 fine-tune 모델(Mamba, RMT), (ii) RAG를 붙인 대형 모델(Llama3.1-8B), (iii) 극단적으로 큰 모델(GPT-4, GPT-4o-mini, Qwen2.5-72B, Llama3.1-70B)과 비교한다(그림 6b). Titans는 GPT-4 같은 극대 모델조차 능가한다. RMT 같은 메모리 부착 Transformer 대비 더 나은데, RMT는 과거를 16 크기 vector 값 메모리로 압축하는 반면 Titans는 in-context online 메모리 학습기로 과거를 매개변수에 부호화하기 때문이다. 흥미롭게도 Llama3.1-8B에 RAG를 붙여도 약 70배 적은 매개변수의 Titans보다 성능이 낮다.

### 5.5 Deep Memory의 효과

deep memory가 wall-clock 학습 시간과 성능에 미치는 영향을 평가한다. neural memory 모듈의 $L_{\mathcal{M}} = 1, 2, 3, 4$ 변형에 집중하고, Mamba를 성능 baseline으로 쓴다. 공정한 비교를 위해 모두 같은 학습 절차로 Pile 데이터셋 부분집합에서 학습한다.

sequence 길이의 함수로 perplexity를 보면(그림 7), 메모리 깊이 $L_{\mathcal{M}}$이 커질수록 모든 sequence 길이에서 더 나은 perplexity를 얻는다. 또 깊은 메모리는 매개변수 수가 적을 때 sequence 길이에 더 강건하다. 매개변수가 늘면 모든 모델이 긴 sequence에서 더 나은 성능을 보인다.

메모리 깊이가 학습 throughput에 미치는 영향도 본다(그림 8). 모든 모델이 context 길이에 대해 선형으로 확장된다(초당 토큰 수가 sequence 길이에 대해 상수 추세). 다만 메모리 깊이가 커지면 예상대로 학습이 선형적으로 느려진다. 따라서 깊은 메모리가 늘 효율적인 것은 아니며, 효과성과 효율성 사이의 절충이 존재한다.

## 6 결론 (Conclusion)

이 논문은 meta in-context learner로서 test time에 기억하기를 학습하는 neural long-term memory를 제시했다. 이 메모리 모듈은 본질적으로 recurrent 모델이며, 더 놀랍거나 놀라운 토큰에 가까운 토큰들을 적응적으로 기억한다. 최신 recurrent 모델과 비교해 더 표현력 있는 메모리 갱신·저장 메커니즘을 갖는다. 이 메모리를 써서 우리는 Titans 아키텍처와 세 변형 — 메모리를 (1) context로, (2) gating으로, (3) layer로 통합 — 을 제시했다. 다양한 과제에 대한 실험은 Titans가 특히 긴 context에서 Transformer와 최신 linear recurrent 모델보다 더 효과적임을 확인해 준다. 즉 Titans는 2M 이상의 context window로 확장되면서도 baseline보다 나은 정확도를 낸다. Titans는 PyTorch와 JAX로 구현되었으며, 학습·평가에 쓴 코드는 곧 공개할 예정이다.

## 부록 A: 관련 연구 (Related Work)

Titans 혹은 그 구성 요소로 독립적으로 이어질 수 있는 여러 관점이 있다. 세 범주로 나누어 살펴본다.

### A.1 Linear Recurrent 모델

Transformer의 학습·추론 비용을 줄이기 위해 linear recurrent 모델이 큰 주목을 받았다. **1세대**(RetNet, LRU, RWKV, S5, S4)는 데이터 무관 전이 행렬/감쇠 메커니즘을 쓴다. **2세대**는 전통적 RNN의 gating을 이런 linear 아키텍처에 도입했다(Griffin, SSM 계열, RWKV6). **3세대**는 meta-learning, online learning, delta-rule에 기반한 더 복잡한 메모리 갱신 규칙을 써서 더 표현력 있는 모델을 낸다(Longhorn, Gated DeltaNet, TTT, DeltaNet). 우리 LMM은 토큰 흐름(token flow)을 메모리 갱신에 통합한, 이런 모델들의 **다음 세대**로 볼 수 있다.

### A.2 Transformer 기반 아키텍처

**Transformer**는 attention 기반의 사실상 표준 backbone이나 제곱 비용으로 긴 context 확장이 어렵다. 이를 개선하려는 연구는 I/O 인지 구현, attention 행렬 희소화, softmax 근사, kernel 기반(linear) attention으로 나뉜다.

**Segment 기반 Transformer.** 또 다른 방향은 segment/chunk 기반 Transformer다. chunk Transformer의 단점은 segment가 완전히 분리되어 context window가 chunk 길이로 제한된다는 것이다. 이를 해결하려 여러 연구가 chunk 간 정보 전달을 돕는 메모리의 중요성을 논했다. Titans와의 핵심 차이는 (1) 이런 모델의 메모리는 단순한 작은 vector라 복잡한 정보 압축에 표현력이 부족하고, (2) forget 메커니즘이 없어 빠른 오버플로가 나며, (3) momentary surprise에만 집중해 정보 흐름을 놓친다는 점이다. 특히 Recurrent Memory Transformer(RMT)에 견주면, Titans (MAC)는 vector 값 소형 메모리 대신 neural memory 모듈을 쓰는 RMT의 일반화로 볼 수 있다.

**LLM을 위한 메모리.** 학습 후 LLM에 외부 메모리 모듈을 붙이는 방향도 있다. 우리 접근과 달리 이들은 메모리를 초기 아키텍처의 일부로 두어 end-to-end 학습하지 않으며, 대부분 chunk 기반 Transformer와 같은 한계를 겪는다.

### A.3 Test Time Training과 Fast Weight Program

**메모리 설계와 증강.** 문헌에서는 지식 추상을 기억하는 메모리(persistent memory)나, recurrence/Transformer/gradient 등으로 데이터 의존 정보(contextual memory)를 기억하는 모듈을 설계하려는 노력이 많았다. 그러나 이들은 (1) momentary surprise 기반이라 데이터 흐름·사건을 놓치거나, (2) forget 메커니즘이 없어 빠른 오버플로가 나거나, (3) 고정 크기의 얕은(matrix 값) 메모리라 긴 context에서 성능이 부실하거나, (4) test time에 매개변수가 고정되어 적응이 없다.

**Fast Weight Program.** 선형 layer를 key-value 메모리로 보는 발상은 fast weight program으로 거슬러 오르며 Hebbian·delta 규칙이 널리 쓰였다. 그러나 이들 모두 momentary surprise 기반이라 토큰 흐름을 놓치고 대부분 forget gate가 없어 메모리 관리가 부실하다.

**Test Time Training.** test time에 학습하기/learning to learn의 핵심 발상은 local learning의 초기 연구(각 test 표본을 예측 전에 이웃으로 학습)로 거슬러 오른다. 우리와 가장 유사한 연구는 MNM과 TTT-layer이며, 그 핵심 차이는 부록 C에서 논한다.

## 부록 C: Sequence 모델로서의 LMM (LMM as a Sequence Model)

LMM이 sequence 모델로서 최신 linear recurrent 모델과 어떻게 연결되는지 논한다. 단순화를 위해 선형 메모리 $\mathcal{M}_t = W_t \in \mathbb{R}^{d_{in} \times d_{in}}$부터 시작한다. 이 경우 목적함수는 $\ell(\mathcal{M}; x_t) = \tfrac{1}{2}\|\mathcal{M}_t k_t - v_t\|_2^2$가 되고, momentum·weight decay를 동반한 gradient descent로 최적화한다. 식 (13)의 recurrence를 다시 보면,

$$\mathcal{M}_t = \mathrm{diag}(1 - \alpha_t)\,\mathcal{M}_{t-1} + S_t \tag{32}$$
$$S_t = \mathrm{diag}(\eta_t)\,S_{t-1} - \mathrm{diag}(\theta_t)\big(\mathcal{M}_{t-1} k_t^\top k_t - v_t^\top k_t\big) \tag{33}$$

**LMM은 Gated DeltaNet의 일반화다.** DeltaNet은 $\mathcal{L} = \tfrac{1}{2}\|S_t k_t - v_t\|_2^2$를 최적화하는 online learning 문제로 해석될 수 있고, 이는 다음을 낳는다.

$$S_{t+1} = S_t - \theta_t \nabla \mathcal{L} = S_t\big(I - \theta_t k_t k_t^\top\big) + \theta_t v_t k_t^\top \tag{34}$$

Gated DeltaNet은 여기에 weight decay 항을 더한 것이다. 식 (32)와 (34)를 비교하면 $\eta_t = 0$으로 두면 두 식이 동치가 된다. 따라서 LMM은 Gated DeltaNet을 세 측면에서 일반화한다.

- **Momentum 기반 규칙**: Delta Rule은 momentary surprise 기반이라 토큰 흐름이 메모리 갱신에 영향을 주지 못한다. LMM은 momentum 규칙으로 과거와 순간의 놀라움을 모두 고려한다.
- **Deep Memory**: Gated DeltaNet은 닫힌 recurrence 형태가 필요해 선형(matrix 값) 메모리에 제한되지만, LMM은 gradient 기반 정식화로 deep memory를 허용해 표현력이 더 크다.
- **비선형 recurrence**: DeltaNet/Gated DeltaNet은 선형 recurrence이지만, LMM은 **inter-chunk 비선형 + intra-chunk 선형** recurrence를 써서 표현력이 더 크다.

RWKV-7 등도 같은 정식화와 손실을 쓰므로 LMM은 이런 모델들을 모두 일반화한다.

**LMM은 Longhorn의 일반화다.** Longhorn은 같은 손실을 쓰되 implicit online learning으로 닫힌 형태를 유도한다.

$$S_{t+1} = S_t\big(I - \delta_t k_t k_t^\top\big) + \delta_t v_t k_t^\top, \tag{35}$$

여기서 $\delta_t = \tfrac{\theta_t}{1 + \theta_t k_t^\top k_t}$이다. 그러나 forget gate가 없어 오버플로가 더 빠르다. 따라서 (1) momentum 규칙, (2) deep memory, (3) 비선형 recurrence에 더해, LMM은 (4) **forget gate**의 이점을 가져 메모리 관리가 낫다.

**LMM은 TTT layer의 일반화다.** 우리가 아는 한 TTT는 gradient 기반 갱신 규칙을 가진 유일한 최신 linear recurrent 모델이다. LMM은 TTT와 세 가지 핵심 차이가 있다. (1) **Forgetting 메커니즘**: TTT는 매 시점 메모리를 갱신하되 과거를 잊을 기회가 없어, 메모리 크기를 고정하면 긴 sequence를 관리하지 못한다. LMM의 forget 메커니즘은 아주 오래된 정보가 더 필요 없을 때 메모리를 비운다. 이 forget이 일반적으로 weight decay와 동치이며 병렬 학습에 빠르게 통합됨을 보였다. (2) **Momentum 기반 갱신 규칙**: TTT는 momentary surprise 기반이지만 LMM은 momentum 규칙으로 과거와 순간의 놀라움을 모두 고려한다. (3) **Deep Memory**: TTT-layer도 더 깊은 메모리를 허용하지만 그 장단점을 실험적으로 평가한 적이 없다.

우리가 아는 한, 우리 neural long-term memory 모듈은 **momentum 기반 갱신 규칙을 가진 최초의 linear recurrent 모델**이다. 끝으로, Griffin·DeltaNet·Gated DeltaNet·H3·Mamba2·Samba 등 최신 linear 모델의 hybrid 변형은 모두 순차적 layer 단위 설계에 기반한다. Titans는 이런 메모리 모듈을 아키텍처에 얼마나 효과적으로 통합할 수 있는지를 보인다.
